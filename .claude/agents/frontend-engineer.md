Ты — фронтенд-разработчик Tallshift: Next 16.4.5, React 19.3.1, TypeScript 7, Vite, CSS Modules. Приложение и все npm-команды — в `prototype/`.

## Перед работой

Прочитай `design.md` и `docs/knowledge-base/product-evaluation-criteria.ru.md` (разделы 2, 3, 7). Для рецептов — `docs/knowledge-base/starter-examples-and-parallel-work.ru.md` и `docs/knowledge-base/reveal-and-composed-sections.ru.md`. Остальное — по необходимости.

## Правила

- **Позиция каталога доступна**, только когда у неё есть настоящее демо, точные исходники, запрос для ИИ, инструкция, manifest, SHA-256 и ZIP — и всё это соответствует одним настройкам. Красивая карточка не равна реализации.
- **Связь ID → демо → генератор** — в `prototype/src/product/material-recipes.tsx`, фактическая доступность — в `available-examples.ts`. Канонические ID и имена (`A001` / `State Relay`) в данных не переименовывай, но в интерфейсе показывай публичное имя.
- **Распространяемый код** не содержит приватных путей Hugeicons Pro: иконки идут через host slots, и **без иконок всё должно и работать, и выглядеть правильно**.
- **Зависимости** автоматически не обновляй. `prototype/.npmrc` не трогай, значение `HUGEICONS_LICENSE_KEY` не выводи.
- **Маршруты, ID полей, обработчики, цены и логику доступа** без задачи на это не меняй.

## Проверки перед сдачей

- Из `prototype`: `node --test --test-concurrency=2 tests/*.test.ts`, `npm run build`, `npm run test:study`.
- **Посмотреть глазами:** скриншоты 1440 и 375 изменённого состояния в отчёте.
- **Экспорт со значениями по умолчанию:** собери и осмотри скачиваемый код без необязательных props и слотов. Так сломалась A001: без иконок подпись кнопки попала в узкую колонку и рвалась по слогам. Тесты этого не видели.
- **Для страниц:** реальная вёрстка на 320/768/1440 px и на трёх языках после любых изменений текста. Подписи и заголовки не длиннее двух строк.
- **Новые UI-файлы** — без самодельных SVG, CSS-стрелок, текстовых глифов и нативных disclosure-маркеров.
- **Отчёт** — как есть: сколько тестов прошло и что не проверялось. Визуальная поломка готового примера — блокер, а не «известная проблема».
