# Tallshift — стенд арт-направления

Текущий стенд выбранного Afterlight: **[Foundations / 06 — foundations/review.html](foundations/review.html)**. **Утверждены Manrope для EN/RU/VI и акцент Saffron Lighter `#EBD183`, hover `#F0DB9B`, pressed `#D8BE74`, на тёмной нейтральной базе.** Стенд объединяет типографическую шкалу и сетку, поиск/фильтры/select/карточки, локальную форму пресета, диалог и обратную связь, настоящую рабочую область A001 и передачу токенов. EN — основной язык. Новые визуальные компоненты остаются кандидатами для согласования; дизайн-система в целом ещё в работе. [Назначение, проверки и ограничения / 06](../docs/art-direction-2026/foundations-06.ru.md).

Исторический **[Foundations / 05](foundations-05.html)** сохраняет прежний набор компонентов и правки фокуса, checkbox и Clear fields. [Отчёт / 05](../docs/art-direction-2026/foundations-05.ru.md). В / 06 добавлены состояния каталога, дерево файлов, menu/popover/sheet и Free/Pro.

Исторический **[Foundations / 04](foundations-04.html)** сохраняет сравнение пяти оттенков Saffron на общей тёмной базе и решение о выборе Lighter. [Его отчёт](../docs/art-direction-2026/foundations-04.ru.md) содержит прежнюю схему экспорта, HEX, снимки и результаты проверок сохранённой версии.

Исторический **[Foundations / 03](foundations-03.html)** сохраняет сравнение Berry, Acacia, Clay и Saffron на приглушённом графите; [его отчёт](../docs/art-direction-2026/foundations-03.ru.md) сохраняет прежние HEX, проверки и снимки. В / 05 применяется утверждённый Saffron Lighter; остальные палитры остаются в архиве и исходных токенах.

Исторический **[Foundations / 02](foundations-02.html)** с более насыщенными цветными подложками сохранён отдельно; [его отчёт](../docs/art-direction-2026/foundations-02.ru.md) сохраняет прежние HEX, проверки и снимки.

Исторический **[Foundations / 01](foundations-01.html)** с общей нейтральной основой сохранён отдельно; [его проверки и снимки](../docs/art-direction-2026/foundations-01.ru.md) относятся к прежней версии.

Предыдущий **[Afterlight / 05](afterlight/review.html)** с исходниками, промптом и ZIP сохранён по прежнему пути; Foundations его не перезаписывает. [Описание и проверки Afterlight / 05](../docs/art-direction-2026/afterlight-v5.ru.md). [Итерация 03](afterlight-03.html) также сохранена отдельно.

Команды из `prototype`: `npm run build:foundations` собирает текущий стенд, `npm run test:system` проверяет цветовые токены, предусмотренные контрастные пары, граф алиасов и Unicode-валидацию формы. Исходники: `prototype/src/foundations`; [актуальный статус проверок / 06](../docs/art-direction-2026/foundations-06.ru.md). Результаты / 04 не переносятся автоматически на / 05. Проверка предусмотренных пар не равна полной WCAG-проверке.

`npm run build:study` пересобирает Afterlight / 05; `npm run test:study` проверяет соответствие preview/кода/промпта/ZIP в 12 комбинациях. Исходники находятся в `prototype/src/study`. Обе сборки используют общий упаковщик; пути результатов раздельные. Корневые `index.html`, `review.html`, `build.mjs` и описанный ниже трёхвариантный стенд сохранены как предыдущая итерация.

Для текущего стенда откройте `foundations/review.html` в современном браузере. Скрипты, стили и локальные шрифты включены в файл. Clipboard может быть ограничен браузером при открытии с диска; предусмотрено ручное копирование текста. Корневой `review.html` — историческая сборка трёх направлений с тремя OFL-шрифтами и локально генерируемой графикой.

Для локальной разработки из этой папки:

```sh
python3 -m http.server 4181 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:4181/foundations/review.html` для текущего системного стенда; `afterlight/review.html` открывает Afterlight / 05, `/` — исторический стенд. Остановка — Ctrl+C. Временный сервер после проверки останавливается; самостоятельные файлы продолжают работать с диска.

Сборка и проверки исторического стенда без npm-зависимостей:

```sh
node build.mjs
node --test tests/*.test.mjs
```

`tokens.mjs` — конкретные кандидаты foundations и расчёт контраста. `tokens.candidates.json` — 18 вариантов и component aliases в собственном формате. `app.mjs` — переключение направления/цвета/языка, геометрия и движение. `specimens.js` — 14 живых семейств. `build.mjs` объединяет их в `review.html`.

Foundations / 06 использует утверждённую основу Saffron Lighter и Manrope; новые шкалы и компоненты имеют статус визуальных кандидатов. `system-scale.ts` хранит числовые основы, `system-tokens.ts` — граф primitive → semantic → component со строгим разрешением алиасов и семантическими CSS custom properties. Handoff JSON передаёт основу, шкалы и токены с общим статусом `visual-review` и `productionReady: false`. Подробности и границы реализации — в [отчёте / 06](../docs/art-direction-2026/foundations-06.ru.md). Это локальный формат, не заявление о полной DTCG-совместимости.

В Discovery показаны шесть записей: A001 доступен как рабочий локальный материал, ещё пять — planned. Форма пресетов сохраняет записи в памяти текущей страницы; обновление очищает список. Аккаунт, серверная запись, оплата и весь каталог не реализованы. Только A001 имеет настоящий комплект demo/кода/промпта/инструкций/ZIP; показ остальных карточек не означает готовности материалов. В реестре 44 семейств — 35 рабочих и 9 частичных образцов. Это покрытие стенда, а не production-приёмка.

Параметры выбора цвета и схема JSON версии / 04 сохранены в её историческом отчёте. Исторический стенд трёх направлений использует `direction`, `accent`, `lang`.

Геометрия и код этюдов созданы для проекта. Шрифты Manrope, Unbounded, Golos Text взяты из официального Google Fonts repository; OFL, исходные metadata, URL и реальные SHA-256 сохранены в `assets/fonts`. Это существующие проверенные шрифты, выбранные за характер и поддержку кириллицы; они не выдаются за новые релизы 2026 года. Источники цветов и исследования: `../docs/art-direction-2026/README.ru.md`.
