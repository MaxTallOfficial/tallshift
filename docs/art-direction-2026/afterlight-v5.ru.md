# Afterlight / 05 — английский основной, EN/RU/VI и новая редактура

22 октября 2026, Asia/Saigon. Пользователь задал EN как основной язык и добавление VI. Конкретная редакция текста, визуальный стиль и акцент остаются на просмотре; эта работа не означает утверждения дизайн-системы.

[Открыть текущий самостоятельный HTML](../../art-direction/afterlight/review.html). [Итерация 04](../../art-direction/afterlight-04.html) сохранена отдельно.

## Текущий результат

Без параметра языка открывается EN. Переключатель явно показывает EN / RU / VI; названия для доступности — English / Русский / Tiếng Việt. Локаль меняет текст, язык документа, заголовок вкладки и описание. Явный выбор в URL сохраняется. Неподдерживаемое значение возвращает английский.

Переписаны главный заголовок, пояснение продукта, подписи настроек, действия, статусы и ошибки. Вместо оценки «Expressive UI» — «Choose a component. Make it yours.»; вместо «Material» — «Component»; вместо «Keep the character» — «Keep this design». Текст описывает выбор компонента, адаптацию и получение кода. Технические ограничения остаются в промпте и инструкции; обычный статус копирования сообщает результат действия. Скопированное демо — текстовый пример, а не исходник компонента; сообщение об успехе больше не предлагает вставить этот текст как код в проект.

VI охватывает весь текущий A001: интерфейс, демо, статусы, код с выбранной локалью, оба режима промпта, README/INSTALL/INTEGRATE и ZIP. Список исходников теперь содержит 21 файл; ZIP дополнительно включает итоговый промпт и checksums.json — всего 23. Имена файлов, API и состояния в коде сохраняют технические идентификаторы.

Для VI используется встроенный Manrope. Cmap файла проверен на предварительно составленные вьетнамские буквы; у встроенного Golos Text часть этих букв отсутствует. У VI-заголовка увеличен интерлиньяж. Добавлять или загружать новые шрифты не потребовалось.
