# Язык и редактура продукта

Английский — основной язык продукта. Русский и вьетнамский — полноценные локализации интерфейса, примера, промпта и инструкции. Это решение пользователя. Конкретные формулировки ниже — текущая редакционная версия, а не утверждённый пользователем tone of voice.

Основное обещание: выбрать компонент, попробовать его и забрать код для своего проекта. Промпт помогает адаптировать код, инструкция — подключить его. Пишем сначала на английском, затем передаём смысл на русском и вьетнамском. Порядок слов и длину фраз подбираем для каждого языка отдельно.

## Как звучим

Понятно, спокойно и предметно. Говорим, что человек может сделать и что получит. Называем кнопку кнопкой, файл файлом, код кодом. Вместо оценки дизайна описываем поведение: кнопка копирует текст, подтверждает результат и позволяет повторить действие при ошибке.

Не используем «характер», «авторскую подачу», «выразительность», «новый уровень», «бесшовную интеграцию» и другие общие оценки вместо объяснения пользы. Не обещаем внедрение без усилий, безошибочный AI, проверенную production-готовность или наличие всего будущего каталога. Сейчас реальный интерактивный пример — A001 State Relay.

Названия действий короткие и предсказуемые: **Demo / Code / Prompt**, **Copy code**, **Copy prompt**, **Download ZIP**. Описания объясняют содержимое, а не повторяют заголовок. В обычном сценарии не добавляем предупреждения о внутренней реализации. Ошибка появляется после неудачного действия и предлагает конкретный следующий шаг.

## Термины

| Смысл | English | Русский | Tiếng Việt |
| --- | --- | --- | --- |
| Переиспользуемый элемент UI | component | компонент | component |
| Секция страницы | section | секция | khối giao diện |
| Анимационный приём | animation | анимация | hiệu ứng chuyển động |
| Исходные файлы | source / source code | код / исходный код | mã nguồn |
| Вкладка с исходниками | Code | Код | Mã nguồn |
| Инструкция для AI | prompt | промпт | prompt |
| Настройка оформления под существующий проект | Match my project | Подстроить под проект | Theo thiết kế dự án |
| Пакет файлов для скачивания | ZIP | ZIP | tệp ZIP |
| Инструкция по подключению | setup guide | инструкция по установке | hướng dẫn tích hợp |

Вьетнамские **component** и **prompt** оставлены как технические термины; section и animation переданы как khối giao diện и hiệu ứng chuyển động, вкладка Code — как Mã nguồn. Обычные подписи и пояснения локализованы. Это рабочая редакционная версия; проверка носителем вьетнамского языка не проводилась.

## Ритм и ограничения

Hero содержит короткое действие в двух строках. Следующий абзац объясняет React, код, промпт и инструкцию. Технические детали переходят к соответствующим элементам: конфигурация — рядом с настройками, полный код — во вкладку Code, инструкция — в пакет.

Не сокращаем язык до телеграфного набора существительных. Не повторяем «ваш» в каждой подписи. Точки ставим в предложениях; названия вкладок, кнопок и полей обходятся без них. Подтверждение не должно обещать больше, чем известно приложению: создание ZIP не равнозначно завершённому скачиванию.

В текущей итерации для вьетнамского выбран **Manrope**: локальный файл покрывает предварительно составленные вьетнамские глифы, включая ộ, ợ, ự и ỹ. У используемого Golos Text этого покрытия нет. Это проверка набора глифов файла, а не обещание корректного рендера любой последовательности комбинируемых знаков. Визуально проверить ă, â, đ, ê, ô, ơ, ư и тоны, межстрочный интервал и отсутствие подстановки другого шрифта. Название бренда сохраняет отдельные настройки.

Текущие тексты интерфейса: `prototype/src/study/copy.ts`. Этот файл хранит одинаковый набор ключей EN/RU/VI, а выбор языка всегда показывает собственные названия: English / Русский / Tiếng Việt.


## Коммерческие карточки и офферы

Первый уровень продаёт конкретную пользу для интерфейса или проекта. Следом — короткое объяснение, состав и ясное действие. Например: «Каждому действию — понятный отклик» → исходники, промпт и инструкция → «Попробовать бесплатно».

Каноническое название, ID, формат, лицензия и готовность образуют второй уровень. Плановый статус остаётся видимым; ценовая гипотеза не оформляется как действующая продажа. Статусы оплаты, ошибки, инструкции и предупреждения используют точный прикладной текст. Сильный визуальный акцент получают выбранные фразы и главное действие; все тексты подряд акцентным цветом не выделяются.
