# Понятные тексты и проверка покупки · 06.11.2026

По запросу Max Tall выполнена повторная редактура всех продуктовых страниц для первого посетителя 16–45 лет, параллельно продолжен сценарий покупки. Копирайтер проверял функцию каждого экрана, смысл названий, необходимость блоков, ожидаемый результат действий и текущую готовность продукта.

## Основные исправления

| Было | Сейчас |
| --- | --- |
| Материалы Tallshift | Блоки и анимации для React |
| State Relay / Кнопка с откликом | Кнопка с индикатором выполнения; техническое имя вторично |
| Внутренние английские имена остальных карточек | Функциональные заголовки на выбранном языке для всех 32 примеров |
| Промпт | Запрос для ИИ с объяснением, что скопировать и куда вставить |
| Ваш фреймворк | Тип React-проекта с пояснением Next.js/Vite и требования существующего проекта |
| Открыть демо | Открыть пример |
| Один автор | Для одного человека, с сохранением прежних условий использования |
| Техническое описание iframe и viewport | Переключение ширины и фактический размер примера |

Переписаны главная, каталог, рабочий и запланированные примеры, тарифы, кабинет, пустые состояния, ошибки, подписи действий и новый расчёт покупки на RU/EN/VI. На главной и в каталоге явно обозначен единственный готовый пример; остальные позиции не выдаются за доступные исходники. На запланированной странице ссылка предлагает открыть готовый пример, а не несуществующий код.

В запросе для ИИ согласованы вкладка, кнопка, заголовки читаемого представления и помощь. Технические требования самого запроса сохранены: их адресат — разработчик или ИИ. Инструкция разделена на шаги; в начале объяснено требование существующего React-проекта и путь через ИИ-редактор. Пояснения лицензии начинаются с разрешённых действий, затем называют MIT. Парсеры маркеров, исходники, ограничения исполнения и права на код не изменены.

Уточнена роль настройки цвета: она меняет индикатор и фон успешного результата, а не всю кнопку во всех состояниях. Общий HEX-контрол получил необязательные label/description; продукт связывает описание с полем через aria-describedby. Формат кода цвета объяснён примером, длительность анимации — также в секундах. Сценарий «Пример ошибки» объясняет, что не копирует текст, и показывает, как вернуться к копированию.

## Следующий экран

Добавлен `/{locale}/checkout?plan=product|bundle&example=...` с переходом из сводки тарифов. Показываются выбранный набор, точная сумма существующего quotePricingPlan, новые и уже учтённые элементы, условия использования и разные сроки обновлений. Пример истории покупок сохраняется при возврате к тарифам и смене языка. URL не выдаёт реальные права.

На телефоне имя набора, цена и причина недоступности оплаты стоят перед длинным составом. На широком экране итог остаётся рядом со списком и учитывает липкую шапку. Лишние повторяющиеся предупреждения убраны.

Повторная оплата полностью учтённого набора не предлагается. Проверены Product за $16, All packs за $39, доплата $23 при наличии Product и частичный состав по существующей модели. Платежи, создание заказа, вход и выдача платных файлов не реализованы и не имитируются: продажи явно обозначены как закрытые. Бесплатный рабочий пример доступен без оформления.

- [12 проверок совпадения примера, исходников, запроса и ZIP](evidence/copy-and-checkout-2026-11-06/export-tests.txt) прошли после редакторских изменений в инструкции и примере.
- [Сборка продукта](evidence/copy-and-checkout-2026-11-06/build.txt) и сборка библиотеки компонентов с типами прошли.
- [Защищённая статическая проверка Hallmark](evidence/copy-and-checkout-2026-11-06/hallmark.txt): 0 FAIL / 0 REFLEX / 0 WARN, 17 продуктовых UI-файлов. Это не заявление о чистой проверке всех исторических образцов дизайн-системы.

После просмотра снимка панели на 320 px исправлен перенос одного слова в переключателе анимации. [Дополнительные 3 проверки](evidence/copy-and-checkout-2026-11-06/narrow-labels.json) подтвердили, что подписи RU/EN/VI помещаются целиком.

Ошибок страниц и внешних запросов браузерной проверки не было. Внешний renderer Hallmark не запускался; проверка выполнена локальным скриптом проекта в отдельном браузере. Скриншоты, исходники и запросы не передавались владельцу Hallmark или Together AI.

[Видимые тексты страниц](evidence/copy-and-checkout-2026-11-06/page-text.json) сохранены локально. Это редакторская и техническая проверка, а не доказательство понятности для каждого человека 16–45 лет. Тестов с реальными участниками и отдельной проверки носителем вьетнамского не проводилось. Пользовательское утверждение не заявлено. [Подробный журнал копирайтера](../knowledge-base/copy-review.ru.md).

По просьбе Max Tall экономить GitHub Actions: в этом проходе workflow не запускались, push и публикации не выполнялись. Все перечисленные проверки локальные; предпочтение объединять связанные изменения перед отправкой закреплено в AGENTS.md.
