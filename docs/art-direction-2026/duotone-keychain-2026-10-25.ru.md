# Duotone Rounded, готовые чекбоксы и Keychain — 25 октября 2026

Актуальный набор — **Hugeicons Pro Duotone Rounded 4.3.4**, рендерер @hugeicons/react 1.1.10. Bulk удалён из зависимостей. В SystemIcon 35 семантических имён: прежние 32 и три состояния чекбокса. У всех иконок сохранены штатные заливки и вторичная прозрачность. Только явно заданные автором stroke-контуры получают постоянные 1,5 px на экране; на залитые пути контур не добавляется.

## Чекбоксы

Пользователь отменил увеличенную отдельную галочку и запросил готовые иконки из набора. SystemCheckmark теперь использует CheckmarkSquare02Icon, SquareIcon и MinusSignSquareIcon. Вся иконка рендерится в штатном размере 24 px; внутри неё авторские рамка, галочка и отступы. Отдельного CSS-бордера, синтетической заливки и увеличения знака нет. Штатные контуры этих трёх иконок — 1,5 px. Выбранное состояние акцентное, пустое — нейтральное. Компонент общий для форм, фильтров, checkbox-пунктов меню и мультивыбора; нативная семантика остаётся у родителей.

## Ключ

По прямому запросу пользователя ключ сохранён в macOS Keychain как generic password:

- Label: Tallshift · Hugeicons Pro
- Service: npm.hugeicons.com
- Account: HUGEICONS_LICENSE_KEY

Запись проверена чтением и сравнением в памяти. Доступ всем приложениям не выдавался. Ключ не записывается в исходники, .npmrc или аргументы запуска процессов.

Для последующих установок и сборок добавлен помощник:

```sh
python3 prototype/scripts/npm-with-hugeicons-keychain.py --prefix prototype run test:consumers
```

Он получает ключ из окружения или Keychain, передаёт только в окружение npm и скрывает его, если он встретится в выводе. На CI ключ задаётся через секрет окружения. В конфигурации реестра остаётся только шаблон ${HUGEICONS_LICENSE_KEY}.

## Проверки

110 тестов прошли, включая рендеринг всех иконок в трёх размерах и доступные имена. Стенд и локальный пакет собраны; независимые Next.js и Vite потребители прошли production-сборки с получением ключа из Keychain. Существующие предупреждения Vite сохраняются.

Браузер: на актуальном стенде все SVG используют Duotone Rounded; checked / unchecked / mixed — готовые иконки библиотеки. EN / RU / VI при 320 px без переполнения, список внутри viewport. Внешний CSS-бордер у чекбокса равен 0, авторские контуры SVG — 1,5. Это сохраняет штатные пропорции иконки.
