# Tallshift UI /09 — сообщения и состояния

Дата: 24 октября 2026. Статус: общий React API и локальные примеры. Это не подтверждение полноценной проверки скринридерами, кроссбраузерной проверки или готовности всего продукта.

## SystemBadge

Пассивная метка `children`, `tone` (`neutral | success | warning | error`), `className`. Не кнопка, не live region, без tab stop. Значение выражается текстом (Free / Pro / Planned / Ready), цвет вспомогательный. Метка Pro сама по себе не даёт доступ. Право на скачивание в продукте должен подтверждать сервер.

## SystemInlineAlert

`title: ReactNode`, `children?`, `tone?`, `action?: ReactNode`, `className?`, `announce?: off | polite | assertive`.

По умолчанию статический блок без роли: постоянные подсказки не должны перебивать пользователя при каждом рендере. `polite` использует `role=status`, `assertive` — `role=alert`; оба atomic. Включать только у нового значимого сообщения. Если тот же результат уже озвучивает toast, оставлять `announce=off`. Ошибка с критически важным продолжением должна оставаться рядом с операцией или формой, а не существовать только в уведомлении.

`action` получает готовую кнопку/ссылку от вызывающего кода. Компонент не делает запросов, не скрывает ошибку и не превращает Retry в фиктивный успех.

## SystemToastRegion

Управляемая очередь в потоке документа. API:

- `label`: доступное имя региона, `dismissLabel`: локализованное имя кнопок закрытия.
- `items: readonly { id; title; description?; tone?; action? }[]` — уникальные стабильные ID.
- `onDismiss(id)` — вызывающий код удаляет запись.
- `announcement?: string`: только текст последнего изменения, не вся очередь.
- `announcementKey?: Key`: новое значение для повторного события с тем же текстом.
- `announcementPriority?: polite | assertive | off`, по умолчанию polite.
- `emptyContent?: ReactNode` — содержимое пустой очереди.

Один отдельный announcer остаётся в DOM постоянно. Карточки не имеют `role=status/alert` и не создают вложенных live regions. Изменение очереди само по себе не определяет озвучку: вызывающий код явно передаёт последнее событие. Для важного сообщения можно выбрать assertive, но не по одному лишь красному цвету карточки.

Нет таймеров, автоматического удаления, скрытой обрезки и лимита с вытеснением старых ошибок. Пользователь закрывает сообщение или вызывает явное «Закрыть все». При удалении карточки, содержащей фокус, закрытие переводит его на соседнюю кнопку закрытия, а у последней карточки — на именованный регион. Мышью нельзя увести чужой фокус из другой области. Внешнее удаление очереди и замена произвольного `action` требуют фокусной политики вызывающего кода. В демонстрации Retry перед заменой кнопки переводит фокус на Close той же карточки.

`toastQueueReducer<T extends {id:string}>` — чистый reducer `upsert`, `dismiss`, `clear`. Upsert заменяет существующий ID на прежней позиции, новый ID добавляется в конец; пустой ID игнорируется. Входные массивы не мутируются, произвольный лимит не применяется. Reducer не хранит тексты/время/HTTP-состояние и не является глобальным event bus.

Пример:

```tsx
const [items, dispatch] = useReducer(toastQueueReducer<SystemToast>, []);
<SystemToastRegion
  label="Notifications"
  dismissLabel="Dismiss notification"
  items={items}
  onDismiss={id => dispatch({ type: 'dismiss', id })}
  announcement={lastMessage}
/>
```

Фиксированное положение над страницей, порталы и глобальные сочетания клавиш здесь не навязываются. Для нескольких видимых регионов приложение должно выбрать одного владельца озвучки. Передача live-region JSX внутрь `title/description/action` нарушает этот контракт.

## SystemSkeleton

`width`, `height` принимают значения CSSProperties; `shape: line | circle | block`; `className`. Декоративный `aria-hidden` placeholder без shimmer/анимации. Содержащая область отвечает за `aria-busy`, понятное название загрузки и соответствие размеров будущему содержимому. Placeholder нельзя оставлять вместо сообщения о неудачной загрузке.

В `FeedbackSpecimen` загруженное содержимое и skeleton занимают одну grid-ячейку. Скрытый слой сохраняет размер, загрузка не переключает высоту карточки. Скрытое готовое содержимое исключено из взаимодействия через `inert` и `aria-hidden`. Отдельной live region у skeleton нет.

## SystemEmptyState

`title: string`, `children?`, `action?: ReactNode`, `icon?: SystemIconName`, `headingLevel?: 2 | 3 | 4` (3 по умолчанию). Именованная `section` связана с настоящим заголовком; нет автоматической озвучки и автоматического фокуса. Причину, следующий шаг и реальный обработчик предоставляет вызывающий код.

## Локальный стенд

`FeedbackSpecimen({locale, motionOff?})`, anchor `#feedback`, EN/RU/VI. Состояния сохраняются при смене локали; тексты уже добавленных сообщений перерисовываются на текущем языке. Примеры очереди, retry, фильтра и загрузки работают только в памяти страницы и прямо это объясняют. Нет запросов, таймеров, симуляции аккаунта или серверного сохранения.

Проверка: `node --test tests/feedback-semantics-09.test.ts` — 4 теста чистого reducer и SSR-семантики. Проверяют порядок, замену без мутации, отсутствие вытеснения, единственный announcer, именованные закрытия, статичную ошибку по умолчанию, пассивность badge и skeleton, связь заголовка empty state. TypeScript `tsc -b` проходит. Эти тесты не доказывают реальную речь скринридера, работу фокуса в браузере и визуальную адаптивность; их проверяет интеграционный проход.
