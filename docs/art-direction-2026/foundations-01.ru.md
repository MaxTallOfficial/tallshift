# Afterlight · Foundations / 01 — цвет и типографика

[Открыть исторический стенд Foundations / 01](../../art-direction/foundations-01.html). Эта версия сохранена для истории; её проверки и снимки ниже относятся к прежней общей основе. Текущий результат — [Foundations / 02](foundations-02.ru.md). [Afterlight / 05](../../art-direction/afterlight/review.html) сохранён по прежнему пути.

Цель — выбрать акцент и гарнитуры до дальнейшей проработки экранов. Три палитры и два варианта шрифта показаны на одинаковом UI. Смена настройки и скачивание JSON не означают утверждения.

## Что сравнивается

| Кандидат | Значение или состав |
| --- | --- |
| Berry | `#DCA5BC` |
| Acacia | `#CFD98B` |
| Waterfall | `#8DCABF` |
| Manrope | Одна гарнитура для EN/RU/VI |
| Golos Text + Manrope | Golos Text для EN/RU, Manrope для VI |

Цвета — самостоятельные UI sRGB, а не официальные цифровые конверсии Pantone. Акцент меняет основные действия и выбранные элементы. Цвета успеха, ошибки, предупреждения, фокуса и синтаксиса оболочки остаются одинаковыми во всех палитрах. Сам переносимый A001 сохраняет собственный дизайн: его заливка success использует настраиваемый accent компонента; это отдельная область от статусных образцов оболочки.

EN — основной язык и значение по умолчанию. RU и VI доступны явно. Выбор палитры, шрифта, языка и вкладки сохраняется в URL. Проектные заметки добавляются в промпт без автоматического перевода.

## Что работает

- Реальный A001 State Relay: копирование короткого примера, локальная симуляция ошибки, повтор и сброс.
- Вкладки Demo / Code / Prompt; стрелки, Home и End переключают вкладки с переносом фокуса.
- Код `SelectedExample.tsx` и полный промпт получаются из того же рецепта, который используется в Afterlight / 05. Промпт содержит выбранный цвет, локаль и заметки, исходники и инструкцию.
- Шрифт демо меняется для сравнения. Экспортируемый компонент наследует гарнитуру проекта; выбор Manrope/Golos не добавляет шрифтовые файлы в код компонента.
- Карточки сравнения, образцы типографики, четыре фоновые поверхности, статусы, фокус и недоступный контрол.
- Save this candidate сохраняет JSON с `status: candidate-not-approved`: палитра, типографика, цветовые токены и расчёт контраста. Это снимок решения для обсуждения, не ZIP компонента и не утверждение системы.
- Reduce motion учитывает системное предпочтение и ручной выбор.

| Копирование | API сообщает об успехе; независимое чтение буфера недоступно или возвращает пустое значение. Полная вставка не подтверждена |

Контраст проверен для перечисленных цветовых пар, а не для всех возможных сочетаний. 49/49 не означает полный аудит WCAG. Полная браузерная матрица, 200%/400% zoom, динамическая эмуляция системного reduce, вспомогательные технологии и редактура VI носителем языка не выполнены. Ручной Off отключает переходы и задаёт duration=0. Консоль проверенного стенда не содержит предупреждений и ошибок. 44 семейства дизайн-системы описаны отдельным контрактом; этот стенд не объявляет их реализованными или проверенными.

## Сборка и следующий шаг

Из `prototype`: `npm run build:foundations` и `npm run test:foundations`. Исходники — `prototype/src/foundations`; результат — `art-direction/foundations/review.html` с локально встроенными скриптом, стилями и шрифтами.

После выбора — уточнить тональную шкалу и типографические роли, зафиксировать foundations v1 и довести семейства системы до визуальных спецификаций и реализации. Каталог и остальные экраны следуют после утверждения системы.
