**Пользователь выбрал Saffron Lighter `#EBD183`.** Его состояния: hover `#F0DB9B`, pressed `#D8BE74`. Тёмная нейтральная база Saffron и Manrope для EN/RU/VI сохраняются. Точный акцент утверждён; остальная дизайн-система ещё в работе.

Пять оттенков остаются в / 04 для сравнения на **одной тёмной нейтральной базе Saffron**. Lighter отмечен отдельным бейджем как утверждённый. Временный просмотр другого варианта не меняет зафиксированное решение.

## Выбор, экспорт и статус

Начальный вариант — Lighter. URL содержит `accent=saffron&shade=light`; при временном просмотре другого оттенка меняется `shade`. Manrope закреплён для EN/RU/VI; EN остаётся основным языком. A001, код и полный промпт используют отображаемый акцент; экспортируемый компонент наследует гарнитуру проекта.

JSON сохраняет `reviewVersion: foundations-04`, общий `status: design-system-in-progress` и постоянную запись `approvedColor: {familyId: saffron, shadeId: light, accent: #EBD183}`. Текущий просмотр находится в `palette`: `id: saffron`, `approvedShadeId: light`, вложенный `shade` с `id`, `name`, `accent` и применённые токены. Для Lighter `palette.status: approved-color` и `palette.shade.status: approved`; для остальных — `comparison-candidate` и `candidate`. Просмотр и скачивание альтернативы не меняют постоянную запись утверждённого цвета. Для Lighter имя файла — `afterlight-saffron-light-manrope.tokens.json`.

Berry, Acacia и Clay доступны в архиве / 03 и сохранены в исходных токенах. В текущем UI переключаются только пять оттенков Saffron; альтернативного выбора шрифта нет.

Проверка текущей / 04 завершена:

- `npm run test:foundations`: 10 тестов прошли. Все 49 × 5 пар оттенков (245 сочетаний) проходят заданные пороги. Проверены общая неизменная база, соответствие Original прежнему Saffron, защита от невалидного ID, отдельные объекты темы и default/approved `light`. Минимум для текстовых пар с порогом 4.5 — 7.005:1.
- `npm run build:foundations`: typecheck, production build и автономный HTML прошли. Manrope встроен, начальная подложка — Saffron canvas. `getSaffronTheme()` без аргумента возвращает утверждённый Lighter; прежний API четырёх палитр сохранён для истории.
- Браузер 1440×1000: пять карточек одинаковой высоты (621 px), кнопки выровнены. На всех пяти вариантах акцент и код меняются согласованно, нейтральная база и Manrope одинаковы. Выбор через карточку и radio согласован; копирование кода другой карточки не переключает текущий оттенок.
- Промпт отражает отображаемый акцент и заметки проекта; заметки сохраняются при смене EN/RU/VI. На 320×740 все три языка укладываются в ширину 320 px. После утверждения отдельно проверены default Light, постоянная отметка утверждения, локализация и акцент в промпте на EN/RU/VI. В консоли нет ошибок или предупреждений.
- Скачанный через UI [JSON Lighter](evidence/foundations-04/afterlight-saffron-light-manrope.tokens.json) сверен: `approvedColor`, `approved-color`/`approved`, default/hover/pressed `#EBD183`/`#F0DB9B`/`#D8BE74`, общая база, Manrope и 49/49 пар. Общий статус остаётся `design-system-in-progress`.
