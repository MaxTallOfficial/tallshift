## Назначение

Новый набор проверяет оболочку на задачах библиотеки: найти материал, прочитать состав набора, отличить пустую выдачу от ошибки, перейти между результатами, выбрать реальный исходник и получить файл. Состояния Free/Pro объясняют границы доступа и готовности; сценарий просмотра не создаёт прав, заказов или платежей.

## Новые образцы

- **Library states:** три карточки канонических наборов, фильтрация шестёрки образцов по набору, рабочая пагинация по два материала. Готовность и полное плановое число материалов отделены от числа совпавших образцов. Loading, empty и error выбираются явно как варианты оформления; сетевые запросы и задержки не имитируются.
- **Source navigation:** реальное дерево пяти исходников A001, меню копирования/скачивания выбранного файла, popover с путём и размером UTF-8, модальная панель файлов на узком экране. Это те же файлы и selectedPath, которые использует Code и ZIP; дерево не подменяет исходники заглушками.
- **Free + Pro:** доступный A001 рядом с каноническим PACK-PRODUCT. Цена предложения — «продажи закрыты»; плановая гипотеза отдельно от актуальной продажи. Сценарии без права, pending, owner и ошибки проверки не выполняют авторизацию и не открывают отсутствующие Pro-файлы.

Форма пресетов остаётся только демонстрационным сценарием компонентов. Её именованные наборы существуют в памяти страницы до обновления и не являются утверждённой функцией продукта.

## Передача и границы

Экспорт использует `reviewVersion: foundations-06`, `status: visual-review`, `productionReady: false`. Экспорт содержит 210 токенов с разрешёнными значениями и CSS-мостом. К прежним токенам добавлены component aliases для menu, popover, sheet, skeleton, collection, file tree, offer, entitlement и pagination. В реестре 44 семейств — 35 рабочих образцов и 9 частичных; у каждой строки есть ссылка на место проверки. Реестр описывает только покрытие образцами; наличие образца не означает утверждения дизайна или production-приёмки. Частичными остаются: общий набор иконок, поисковый combobox с подсказками, полная матрица range/number, редактируемый цвет, общий API segmented control, снимаемые множественные фильтры, дополнительные progress-состояния, API изолированного preview и полное семейство motion controls. Точные остатки сохранены в поле `remaining` экспорта.

Навигация стенда учитывает новые разделы, восстанавливает начальный якорь после монтирования и рассчитывает текущий раздел по фактическому положению, включая возврат к началу страницы.

## Проверки

Выполнено:

- `npm run test:system`: 19 тестов прошли. Добавлены проверки точного состава, доступа и ценовой гипотезы наборов по каноническому `catalog.json`; готовность образцов сверяется с `implementation_status`. Проверки токенов/алиасов, контраста и Unicode-валидации продолжают проходить.
- `npm run build:foundations`: TypeScript и упаковка самостоятельного HTML прошли. Экспортируемый исходник A001 в этой итерации не менялся; 12 export-комбинаций / 05 повторно не запускались.
- В браузере EN/RU/VI × 1440/768/320 px не дают горизонтального переполнения, используется Manrope. Дерево и код на 320 px переходят в одну колонку. [Измерения](evidence/foundations-06/responsive.json).
- Пагинация прошла страницы 1→2→3; на границе фокус сохраняется у Next с `aria-disabled`, повторное действие блокируется. Выбор Playful с третьей страницы возвращает страницу 1 и один реальный E004. Loading показывает два статичных skeleton и `aria-busy`; empty/error и восстановление локальной выдачи проверены. При восстановлении фокус переходит к заголовку результатов.
- Выбор CSS в дереве обновляет общий select и исходник. Popover показывает реальный путь, тип и размер 7609 байт; Escape закрывает его и возвращает focus. Menu ArrowDown/ArrowUp/Home/End/Enter работает; после действия focus возвращается на trigger. Copy подтверждён состоянием `Copied`, независимое чтение системного буфера не выполнялось.
- Скачанный через меню [CSS](evidence/foundations-06/AfterlightExample.module.css) побайтно совпал с исходником. [SHA-256 и сверка экспорта](evidence/foundations-06/download-verification.json).
- На 320 px native dialog sheet открывает только модальную область; Tab с последнего файла переходит к Close, Shift+Tab с Close возвращается к последнему файлу. Escape и выбор файла закрывают sheet и возвращают focus на Files. Выбор `src/useStateRelay.ts` согласован с select и кодом. Информационный popover укладывается в 320 px: left 16, right 288, width 272.
- Все шесть сценариев доступа переключены стрелками нативной radio group. Только Free A001 имеет рабочее действие; у пяти Pro-сценариев действие недоступно, в том числе у Owner. [Результаты](evidence/foundations-06/access-states.json).
- Скачанный через UI [JSON / 06](evidence/foundations-06/formrift-afterlight-system-06.tokens.json) сверен: 210 токенов и разрешённых значений, нейтральный focus, 44 записи покрытия с местом проверки, 49/49 предусмотренных контрастных пар. Общий статус остаётся `visual-review`, `productionReady: false`. После последней сборки консоль браузера не содержит ошибок или предупреждений.

## Уточнение высоты и коммерческой подачи · 23 октября 2026

[Состояние до правки](../../art-direction/foundations-06-before-copy.html) сохранено отдельно. Ниже — результаты текущей версии.

Demo / Code / Prompt размещены в одной grid-ячейке. Неактивные панели сохраняют место по фактической раскладке, скрыты визуально, `aria-hidden` и `inert`; на экране и в доступном дереве остаётся текущая панель. Коду и промпту выделены собственные прокручиваемые области: код 560 px desktop / 440 px mobile, промпт 680 / 600 px. Короткий исходник не сжимает просмотрщик. В панели действий Demo появилась рабочая кнопка получения ZIP, поэтому ряд действия больше не исчезает на мобильном.

Конечные страницы каталога, loading/empty/error и шесть сценариев доступа тоже используют общую grid-ячейку с резервированием высоты самого высокого локализованного варианта. Текст карточек и сообщений не обрезается. В range закреплена собственная геометрия, подсказка и ошибка ввода занимают общую область.

Коммерческие карточки теперь ведут от пользы к составу: отдельный крупный заголовок, короткое объяснение, конкретные материалы и действие. Каноническое имя, ID, лицензия и готовность остаются вторым уровнем. Например, «Каждому действию — понятный отклик», «Покажите продукт. Раскройте его ценность», «Покажите главное с первого экрана». Для Free работает переход к демо/коду; Pro остаётся плановым предложением без действующей продажи. EN — основной текст, RU/VI локализованы.
