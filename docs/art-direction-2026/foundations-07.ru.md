# Afterlight · Foundations / 07 — полный набор для общего просмотра

Работа начата 23 октября 2026. [Самостоятельный стенд](../../art-direction/foundations/review.html), [сохранённая / 06](../../art-direction/foundations-06.html), [API новых компонентов](component-api-07.ru.md).

Три субагента параллельно реализовали поиск, прогресс и превью; иконки и переключатели; настройки цвета и движения. Владелец стенда объединил их, добавил составные фильтры, согласовал токены и экспорт, проверил общую работу в браузере. Во время независимого ревью исправлены повторный запуск анимации и отдельный выбор Subtle / Expressive.

Основа сохраняется: Afterlight Instrument, Manrope EN/RU/VI, Saffron Lighter `#EBD183`, тёмный графит, нейтральный focus. Английский остаётся языком по умолчанию. Продуктовые экраны ещё не начаты.

## Поведение и согласованность

Поиск свободный. Выбор подсказки подставляет каноническое название и сужает карточки; он не открывает отсутствующий материал. Planned остаётся явно обозначенным и недоступным для скачивания. В каждой группе фильтров значения соединены через OR, группы и запрос — через AND. Снятие чипа сохраняет остальные критерии и передаёт фокус соседнему; после последнего — кнопке раскрытия фильтров.

HEX изменяет только A001. Применённый акцент и профиль движения вместе с длительностью поступают в реальное демо, выбранный исходник, промпт и ZIP. Утверждённые токены оболочки остаются Saffron. JSON отдельно сохраняет `specimenConfig`, чтобы пользовательская настройка не выглядела изменением утверждённой палитры. Имя ZIP для своего цвета включает HEX.

В A001 устранён пограничный случай контраста полутонов. Тёмная надпись `#101713` используется при контрасте ≥4.5:1; иначе белая, если проходит; иначе чёрная. Редактор показывает ту же фактическую пару. У утверждённого Saffron сохраняется прежняя тёмная надпись.

Превью использует постоянный пустой `srcDoc` и доверенные React children через portal. `sandbox="allow-same-origin"` не включает scripts/forms/popups. Стили и переменные передаются в отдельный документ, media queries работают относительно его ширины. Это изоляция локального материала, а не обещание безопасного исполнения произвольного загруженного кода. Резерв высоты учитывает язык, выбранный размер и фактическую ширину; высокий новый контент может увеличить резерв. Нулевой CLS для любого будущего материала не заявляется.

Progress показывает явно названный локальный пример. Нет фиктивной загрузки файлов или серверного прогресса. Неопределённое ожидание запускается и останавливается пользователем. При Off/reduce полоса остаётся неподвижной; смысл сохраняется в тексте.
