# Tallshift UI / 08 — общие компоненты и состояния

Продолжение /07: утверждённые Manrope, Saffron Lighter и тёмный графит сохранены. Задача итерации — перевод локальных контролов в общие типизированные компоненты, проверка краевых сценариев и прозрачный учёт готовности. Детальные продуктовые экраны не входят в эту итерацию.

## Состав

Три агента работают в отдельных областях: поля и выбор; действия и вкладки; аудит поиска, select и segmented control. Интеграция, проверка стенда и реестр выполняются основным агентом.

- [Поля и выбор](form-primitives-08.ru.md): input, textarea, checkbox, radio group, switch. Общие компоненты используются в форме локального пресета; дополнительные состояния вынесены в раскрываемую панель.
- [Действия и вкладки](action-primitives-08.ru.md): общие кнопки, icon button и tabs с автоматической и ручной активацией; интерактивный образец.
- [Аудит поиска и выбора](control-audit-08.ru.md): конкретные исправления существующих компонентов и границы проведённых проверок.
- Реестр `system-registry.ts` отделяет общий API от композиции на общих контролах и локального образца. Визуальное утверждение и проверка выпуска остаются отдельными полями со значением `pending`.

Общие компоненты остаются исходниками внутри прототипа. Это ещё не отдельный опубликованный пакет. Его установка, версионирование, SSR/hydration в реальных Next.js/Vite проектах и поддержка потребителей требуют отдельной проверки.

## Критерии завершения системы

Для каждого семейства нужны четыре результата: API и правила композиции; применимые состояния и адаптивность; документация и примеры; подтверждённые проверки. Наличие образца само по себе не закрывает ни выпуск, ни пользовательское утверждение.

После /08 остаются локальными: brand mark и роли типографики (это правила/стили), text link, badge, tooltip, popover, menu, dialog, sheet, accordion, toast, inline alert, skeleton, empty/error state, карточки материалов/наборов, catalog toolbar, code/prompt panels, download action, offer/price, entitlement, navigation shell и pagination. Часть из них уже работает в стенде, но ещё не имеет общего независимого контракта. Композицию не обязательно превращать в универсальный компонент: решение зависит от повторного использования и требований продукта.

Следующие работы по системе:

1. Общие overlays: dialog/sheet, menu/popover, tooltip; контракт фокуса, Escape, вложенность, прокрутка и возврат фокуса.
2. Общая обратная связь: alerts, toast queue, badge, empty/error, skeleton; разделить визуальный статус и live-объявление.
3. Композиции каталога и рабочей области: API данных, действия карточек, pagination, code/prompt/download и shell. Сохранить точность скачиваемых исходников и отсутствие фиктивных прав доступа.
4. Проверки Safari/Firefox/Chromium, реальный touch и VoiceOver/NVDA, forced-colors, zoom, reduced motion и длинные переводы. Браузерная DOM-проверка не заменяет тест скринридером.
5. Отдельное визуальное утверждение пользователем и пакетирование библиотеки после стабилизации контрактов.

## Проверка этой итерации

- `npm --prefix prototype test`: 60/60. В том числе 15 новых SSR-проверок разметки полей, действий и выбора, а также проверка честности реестра API. SSR не проверяет события или работу скринридера.
- `npm --prefix prototype run test:study`: 12/12 случаев точности preview/source/prompt/ZIP. Это не сборка целевых Next.js/Vite приложений.
- `npm --prefix prototype run build:foundations`: TypeScript и сборка проходят; standalone HTML 1 169 137 байт. Сохраняется предупреждение о JS chunk больше 500 kB: стенд включает все образцы, исходники и шрифты, это не бюджет опубликованного приложения.
- IAB Chromium: EN/RU/VI × 320/768/1440, включая раскрытые краевые состояния; горизонтального переполнения страницы нет.
- Реальная форма: пустое имя вызывает ошибку и фокусирует поле; загрузка примера и сохранение добавляют пресет.
- Checkbox: accessibility tree показывает mixed (2); после активации — checked (1).
- Manual tabs: стрелка перемещает фокус без выбора; Enter выбирает вкладку. Кнопка pending сохраняет имя, фокус и размер 148.28 × 48 px.
- Workbench RU: высота контейнера 775.53 px для Demo → Code → Prompt → Demo, изменение 0 px.
- Select: стрелка пропускает недоступный пункт, Enter выбирает Vite; readOnly остаётся закрытым. Неизвестное значение показывает тире.

[Машиночитаемые результаты браузерной проверки](evidence/foundations-08/browser-checks.json), [снимок секции действий](evidence/foundations-08/actions-en.png). Старый /07 сохранён в `art-direction/foundations-07.html`. Исторические доказательства /07 не считаются проверкой новых API /08.

В реестре /08: 19 семейств имеют выделенный общий API, locale control использует общий segmented control, 24 семейства остаются локальными образцами или правилами. Наличие API не означает полного покрытия контракта. Например, prefix/suffix у полей ещё не реализованы. Общий entry point `prototype/src/foundations/index.ts` экспортирует примитивы внутри исходников; хост задаёт CSS-переменные темы и шрифт. Компоненты с hooks подключаются из client boundary в Next.js. Отдельного npm-пакета нет.

Проверка этой итерации не включает реальные Safari/Firefox, screen reader, touch-устройство и полную матрицу клавиатуры/zoom/forced-colors/reduced-motion. Визуальное утверждение новых компонентов пользователем остаётся открытым.
