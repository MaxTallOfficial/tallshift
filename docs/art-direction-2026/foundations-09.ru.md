# Tallshift UI /09 — overlays, обратная связь и композиция

Три агента подготовили общие компоненты модальных окон, плавающих поверхностей и обратной связи. Основной агент подключил их к существующим сценариям, дополнил ссылки и раскрываемые блоки, исправил ошибки по результатам браузерной проверки. Утверждённые Afterlight, Manrope и Saffron Lighter сохранены. Продуктовые экраны пока не разрабатывались.

## Что изменилось

- [SystemDialog / SystemSheet](modal-primitives-09.ru.md): контролируемое открытие, начальный фокус, безопасное подтверждение, возврат инициатору или fallback, Escape, длинное содержимое со своим скроллом. Мигрированы удаление пресета и мобильный список файлов.
- [SystemMenu / SystemPopover / SystemTooltip](floating-primitives-09.ru.md): клавиатура и закрытие, disabled/destructive menu items, позиционирование, portal в текущий native dialog при вложенном использовании. Мигрированы действия файла, сведения о нём и подсказка формы.
- [SystemBadge / SystemInlineAlert / SystemToastRegion / SystemSkeleton / SystemEmptyState](feedback-primitives-09.ru.md): локальная очередь с явным закрытием и действиями, отдельное live-объявление, восстановление после ошибки и статические placeholders. Мигрированы сообщения формы и глобального экспорта, badges каталога и состояния выдачи.
- [SystemAccordion / SystemTextLink](disclosure-and-links-09.ru.md): native раскрытие состава Product и общие ссылки реестра/архива.
- Кнопки Free/Pro переведены на SystemButton: в /08 локальные sy-button остались после удаления их общего старого CSS. У ActionSpecimen выделен собственный CSS-префикс act-, чтобы не пересекаться с as- в AccessStatesLab.

В реестре теперь **31 семейство с общим API**, **1 композиция** (locale control) и **12 локальных образцов/правил**. У всех новых семейств визуальное утверждение и release verification остаются pending. Наличие API не означает покрытия всех вариантов контракта или готовности npm-пакета.

## Исправления после живой проверки

1. Native modal в IAB отдавал фокус на body после последнего контрола. Добавлено явное замыкание Tab/Shift+Tab по видимым доступным целям внутри окна.
2. Menu/popover при первом открытии пытались фокусировать ещё скрытую панель. Фокус переносится после расчёта позиции и visibility.
3. Tab с последнего контрола popover в portal уходил в browser chrome и оставлял панель открытой. Теперь он закрывает панель и переходит к следующему контролу после trigger; Shift+Tab с первого возвращается к trigger. В modal поиск ограничен текущим окном.
4. Tooltip обрабатывает Escape в capture только для своего активного контекста. Вложенные слои можно последовательно закрыть, не закрывая всё модальное окно одним нажатием.
5. Действия floating specimen меняют видимый локальный выбор файла; они не изображают копирование без clipboard operation.

## Проверки

- TypeScript и `build:foundations` проходят. Standalone HTML: 1 225 594 байта. Предупреждение о JS chunk >500 kB сохраняется для стенда, включающего все исходники и образцы.
- `npm --prefix prototype test`: **75/75**; это unit/reducer/SSR, без эмуляции событий браузера. После последней правки native accordion его 2 SSR-проверки повторены отдельно.
- `test:study`: **12/12** точности source/prompt/ZIP; целевые Next.js/Vite проекты этим не проверяются.
- IAB Chromium: открытые sheets на EN/RU/VI при 320/768/1440 × 600. Горизонтального переполнения нет, footer остаётся в viewport, длинная инструкция имеет внутренний scroll.
- Menu на 320 × 600 на трёх языках остаётся в viewport; первый пункт получает фокус. ArrowDown пропускает disabled. Escape возвращает trigger; Tab переходит к следующему контролу.
- Popover: первый focus, Escape, выход Tab; nested portal находится внутри открытого dialog. Последовательность Escape: popover → tooltip → modal.
- Modal: начальный focus, Tab/Shift+Tab на границах, Escape/return focus, сохранение черновика после закрытия. Удаление пресета фокусирует безопасную кнопку, после удаления возвращает Save preset. Мобильный file sheet при переходе на desktop закрывается и фокусирует видимую File actions.
- Toast: два сообщения остаются в очереди; retry меняет существующую карточку и сохраняет фокус; закрытие переносит фокус к соседней карточке. Loading specimen: 184 px до/во время loading.
- Native accordion открывается с клавиатуры; содержимое и состав предложения не изменены.

[Численные результаты и границы проверки](evidence/foundations-09/browser-checks.json). Архив /08 сохранён в `art-direction/foundations-08.html`. Доказательства предыдущих итераций не выдаются за проверку новых компонентов.

## Что остаётся

Локальные семейства: brand mark, typography rules, content tile, collection tile, catalog toolbar, code panel, prompt panel, download action, offer/price, entitlement, navigation shell и pagination. Для сложных композиций нужно определить API данных и действий, а не только завернуть текущую разметку.

Дополнительно остаются непокрытые варианты уже выделенных API: prefix/suffix полей, дополнительные модели menu selection и полная матрица вложенных комбинированных контролов. Нужны реальные Safari/Firefox, screen reader (VoiceOver/NVDA), touch, zoom и forced-colors; браузерная accessibility tree не заменяет прослушивание AT. Hover-to-tooltip, реальная assistive technology и все сочетания вложенности не проверены этой итерацией.

Нужны визуальное утверждение системы пользователем, пакетирование и интеграционные проверки Next.js/Vite. Оплата, аккаунты и права доступа не добавлялись. Готовым материалом библиотеки остаётся A001.
