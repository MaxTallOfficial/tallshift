# Иконки и чекбоксы — 25 октября 2026

Утверждённое направление: **Hugeicons Pro Bulk Rounded**. Предыдущие Stroke Standard и Stroke Rounded заменены; смешения стилей в актуальном интерфейсе нет. Публичный API SystemIcon сохраняет семантические имена и размеры 16 / 20 / 24 px, но использует только импортированные иконки Hugeicons. Локальные SVG-иконки из поиска, файлового дерева, кнопок, карточек и превью переведены на этот API.

Bulk сохраняет авторские заливки и вторичную прозрачность. Ему не добавляется искусственная обводка: параметр strokeWidth в общем рендерере не задан. Правило «1,5 px» применяется к рамке чекбокса; для залитой Bulk-иконки это не эквивалент толщины контура Stroke.

SystemCheckmark — единая пассивная геометрия для нативного SystemCheckbox, пунктов мультивыбора и checkbox-пунктов меню: размер 20 × 20 px с border-box, рамка 1,5 px, радиус 5 px, иконка 16 px по центру. Нативная семантика checkbox и множественный listbox остаются у родительских контролов. Checked / mixed / disabled / readonly / error и клавиатурный фокус сохранены. Выбранная рамка нейтральная; знак — акцентный.

Иконки отдельного экспортируемого материала State Relay остаются частью его независимого исходника; для них зафиксирован экранный контур 1,5 px. Они не используют Pro-данные. Исторические HTML-снимки ранних прототипов не пересобираются при изменении текущей системы.

## Подключение и лицензия

Официальная [лицензия Hugeicons](https://hugeicons.com/docs/faqs/license-questions) разрешает использование в интерфейсе сайта и внутренней дизайн-системе. Исходники Pro-иконок не передаются в материалах для скачивания. Внутренний @tallshift/ui сохраняет Pro-пакет внешней peer dependency, без копирования в tarball. Устанавливающий внутренний пакет использует собственную лицензию.

В prototype/.npmrc находится только шаблон переменной HUGEICONS_LICENSE_KEY. Ключ не записан в исходники или Git. Зависимости закреплены точными версиями; ключ использован из буфера только в окружении npm-процесса.

## Проверка

110 тестов прошли, включая рендеринг всех 32 иконок в размерах 16 / 20 / 24 px и доступные имена. 12 проверок соответствия превью / кода / промпта / ZIP прошли. Приватный tarball установлен в независимые Next.js и Vite проекты, production-сборки прошли. Существующие предупреждения Vite о размере чанка и `use client` сохраняются.

В браузере актуального стенда не осталось SVG-иконок вне Hugeicons Bulk Rounded. Геометрия чекбоксов проверена: 20 × 20 px, граница 1,5 px; центры SVG и рамки совпадают (dx=0, dy=0). Проверены клавиатурное переключение checkbox и EN / RU / VI на 320 px: без горизонтального переполнения, список внутри viewport. Полная матрица вспомогательных технологий этим не заменяется.

В tarball нет vendor-папок Pro; import Pro-пакета остаётся внешним. Ключ проверен на отсутствие в файлах проекта.
