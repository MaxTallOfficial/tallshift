# Tallshift UI /09 — модальные окна и панели

Кандидат на проверку. Вынесены общие `SystemDialog` и `SystemSheet`; на них переведены удаление локального пресета в InteractionLab и мобильный список файлов SourceNavigator. `ModalSpecimen` показывает редактор с сохраняющимся черновиком, безопасное подтверждение очистки и длинную инструкцию. EN/RU/VI. Это локальные примеры, без аккаунта и сохранения на сервер.

## API

`SystemDialogProps`:

- `open: boolean` и `onOpenChange(open, reason)` — контролируемое состояние. Причина запроса закрытия: `close-button`, `escape`, `native` (например, форма `method="dialog"`). Родитель принимает запрос и меняет `open`.
- `title: ReactNode` — обязательный заголовок, связан с native dialog через `aria-labelledby`.
- `description?: ReactNode` — короткое пояснение, при наличии связано через `aria-describedby`. Большую инструкцию размещать в `children`, а не в описании.
- `closeLabel: string` — обязательное локализованное имя кнопки закрытия.
- `children: ReactNode`, `footer?: ReactNode` — прокручиваемое содержимое и закреплённые действия. Данные форм принадлежат родителю; закрытие само по себе не сбрасывает поля.
- `initialFocusRef?: RefObject<HTMLElement | null>` — видимый доступный элемент внутри диалога. Без него фокус получает заголовок. При подтверждении удаления передавать ref безопасного действия.
- `returnFocusRef?` — предпочтительный инициатор; далее проверяется элемент, активный перед открытием; `fallbackFocusRef?` — видимая запасная цель при удалении/скрытии инициатора. Скрытые, inert, disabled и отсоединённые элементы исключаются. Передавайте запасную цель, если инициатор может исчезнуть.
- `id?`, `className?` — идентификатор для `aria-controls` инициатора и дополнительный класс.
- `variant?: 'dialog' | 'sheet'` — используйте обёртку `SystemSheet` для панели. Её API совпадает, кроме отсутствия `variant`. **Только модальная** панель: постоянная навигационная боковая панель сюда не относится.

Native `showModal()` включает top layer и изоляцию фона. Escape перехватывается для запроса к контролируемому родителю. Клик по фону не закрывает окно. Корневой scroll блокируется на время открытия и восстанавливается при закрытии/размонтировании; счётчик не снимает блокировку при закрытии одного из нескольких окон. При быстрой смене `open` устаревшее событие close не закрывает уже вновь открытое окно. Содержимое не размонтируется при обычном закрытии. На SSR атрибут `open` намеренно отсутствует: клиентский эффект открывает окно модально, чтобы не создавать немодальный промежуточный показ.

## Внешний вид

Общие кнопки /08, нейтральный focus, графитовая поверхность, один явный primary в редакторе. Подтверждение удаления использует destructive, начальный фокус на отмене. Ширина диалога до 560 px; панель справа до 560 px и на всю ширину на малом экране. Заголовок и действия закреплены, основной контент прокручивается. Анимации открытия нет — нет дополнительной motion-зависимости и ожидания перед вводом.

## Проверки и границы

`modal-semantics-09.test.ts` проверяет SSR: native dialog, связи заголовка/описания, локализованное имя закрытия, отсутствие преждевременного немодального `open`, уникальные ID и владение form у footer submit. TypeScript проверяет интеграцию. Эти тесты **не проверяют** Tab/Shift+Tab, Escape, восстановление фокуса, CSS и screen reader.

Нужна отдельная браузерная проверка: редактор → ввод → Escape → повторное открытие; сохранение submit; начальный фокус отмены в подтверждении; удалённый инициатор → fallback; sheet на узком экране → desktop breakpoint; прокрутка длинной инструкции; zoom и RU/VI длинный текст. Native dialog требует современный браузер с `showModal`; полифилл не добавлен. Поддержка всех браузеров и сочетаний assistive technology не заявляется. Сложные вложенные модальные сценарии и сторонние порталы требуют отдельного тестирования.

Интеграционная проверка обнаружила переход Tab после последнего контрола на body в IAB Chromium. Добавлено явное замыкание Tab/Shift+Tab по видимым доступным целям внутри dialog; native top layer сохраняет изоляцию фона. Полная матрица комбинированных виджетов внутри модального окна ещё требует проверки.
