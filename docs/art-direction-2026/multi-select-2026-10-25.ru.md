# Мультивыбор параметров — 25 октября 2026

`SystemMultiSelect` заменяет меню параметров отображения. Это listbox с множественным выбором, а не меню действий. Параметры независимы: перенос кода, номера строк, уменьшение движения. Прежние взаимоисключающие профили не представлены независимыми чекбоксами.

Выбранные значения сразу отображаются метками в исходном поле. Каждая метка содержит отдельную кнопку удаления с локализованным доступным именем. Нажатие крестика обновляет выбор в списке, сохраняет другие значения и не открывает закрытый список / не закрывает открытый. После удаления фокус переходит к соседнему крестику или к стрелке поля. Вложенных кнопок нет. При пустом выборе отображается подсказка.

Выбор не закрывает список. Space / Enter переключают пункт; стрелки, Home / End перемещают фокус; Escape закрывает список и возвращает фокус к стрелке. Tab выходит из списка. Недоступные пункты не выбираются. Общие ограничения по viewport сохранены. Кнопки удаления имеют область 32 px для мыши и 44 px для touch.

Для нескольких независимых настроек используется этот формат: выбранное видно в поле. Одиночный выбор остаётся SystemSelect, команды остаются SystemMenu. В данном стенде настройки — локальный пример состояния, без изменения исходников рабочего материала.

API: label, placeholder, options, value, onChange, disabled, removeLabel. Компонент экспортирован в приватном пакете и добавлен в реестр как семейство 45; статус визуального утверждения остаётся pending.

Проверки: 108 тестов прошли; стенд и локальный пакет собраны; независимые Next.js и Vite сборки прошли. Существующие предупреждения Vite сохраняются. Браузер: несколько выбранных значений, удаление в открытом и закрытом состоянии, очистка до пустого состояния, Space, Escape и возврат фокуса. EN / RU / VI при 320 px без горизонтального переполнения, список остаётся в viewport.
