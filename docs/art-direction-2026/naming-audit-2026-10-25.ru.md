# Аудит названий — 25 октября 2026

Область: актуальный стенд `art-direction/foundations/review.html`, EN / RU / VI. Исторические версии стендов сохранены как история решений.

## Изменения

- Состав Starter, UI Motion и Playful раскрывается под «Что входит»: названия материалов вместо S001 / C001 / A001. Раскрытие не переключает выбранную коллекцию.
- В Product перечислены шесть материалов обычными названиями. Убрана внутренняя редакция `1.0-launch`; использование и обновления описаны понятными фразами. Статус планируемого набора и закрытые продажи сохранены.
- Идентификаторы убраны из метаданных карточек, подсказок поиска, сообщений доступа, заголовков рабочей области, действий экспорта, примеров полей и пояснений вкладок.
- Для всех 32 материалов есть подписи на трёх языках. Порядок и состав коллекций не изменены.

## Граница между интерфейсом и техническими данными

Канонические ID сохранены в данных каталога, ключах поиска, манифестах, названиях файлов и инструкциях подключения, где они связывают конкретный исходник с материалом. Названия API и токены в разделе передачи разработчику также сохранены. Это не подписи карточек или условия продажи.

`SystemCollectionTile`: вместо `memberIds` принимает `members: { id, label }[]`. Кнопка выбора и раскрытие состава — соседние интерактивные элементы, без вложенных кнопок.

## Проверки

- 102 автоматических теста: подписи всех 32 материалов, точное соответствие составу каталога, отсутствие внутренних ID в основных словарях интерфейса, структура раскрытия.
- 12 проверок соответствия превью / исходника / промпта / ZIP.
- Production-сборка стенда. Сохраняется предупреждение Vite о размере JS-чанка более 500 kB.
- Обновлённый локальный пакет установлен и собран в независимых проектах Next.js и Vite; совпадение JS и CSS с текущей сборкой проверено. Есть предупреждение Vite об обработке `use client`.
- Проверка браузером EN / RU / VI на 320 и 1440 px: без горизонтального переполнения, состав Product содержит 6 названий, Starter — 9. В пользовательских текстах не найдено ID; технические инструкции и код исключены из этой проверки.
