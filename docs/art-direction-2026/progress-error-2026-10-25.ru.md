# Явное состояние ошибки прогресса — 25 октября 2026

В `SystemProgress` при tone=error рядом с процентом показана SVG-иконка и локализованный статус Error / Ошибка / Lỗi. Его текст связан с progressbar через aria-describedby. Дополнительная настройка errorLabel позволяет передать контекстную подпись. Ошибка не определяется одним цветом полосы.

В примере операции добавлено отдельное сообщение с заголовком о неудачном завершении, пояснением повтора, рамкой и согласованным мягким фоном (25% error / 75% surface). Активный повтор остаётся основным действием; недоступные действия не запускаются. После повтора ошибочный статус исчезает, progressbar возвращается в обычное состояние, следующий шаг доступен.
