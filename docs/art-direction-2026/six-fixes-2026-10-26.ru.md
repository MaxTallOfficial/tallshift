# Шесть правок: обратная связь, настройки, цены и файлы

26 октября 2026. Все шесть запросов Max Tall реализованы в текущем стенде и исходниках пакета. Это проверка перечисленных сценариев; статус всего стенда остаётся unapproved visual study, commerce disabled.

## Что изменилось

1. Короткие сообщения формы и сайта выводятся вне потока в общем правом нижнем стеке. SystemToastRegion по умолчанию placement="viewport"; один host на theme/modal складывает сообщения разных производителей. Inline оставлен только явно указанному specimen очереди. Смена состояния уведомления не меняет размеры формы. Ошибки полей остаются рядом с полем.
2. SystemTooltip ограничен 280 px и viewport minus 24 px. Ограничение применяется и в JS-позиционировании: прежнее inline maxWidth шириной экрана больше не отменяет CSS-лимит. Длинный текст переносится; popover с данными сохраняет свою семантику.
3. Тумблеры находятся в одной grid-строке с заголовком. Описание, ожидание и ошибка вынесены ниже. Все три показанных переключателя имеют нулевую разницу центров с заголовками, включая мобильные языковые варианты.
4. Product $16 / All packs $56 разово. Тематические packs выровнены до $16. Каталог, UI, пример disabled-offer и действующее ТЗ синхронизированы. [Разбор ценности и экономики](../spec-v1.0/pricing-review-2026-10-26.ru.md): четыре packs $64, bundle экономит $8; поддержка и комиссии учитываются отдельно. Алгоритм missing IDs сохранён: Product→Bundle $41.40 до налогов, не простая разница $40.
5. Дерево файлов заключено в отдельный контейнер. Верхний разделитель удалён. Имя сокращается через ellipsis в одной строке; расширение (включая .module.css) остаётся полностью видимым. Полный текст имени сохранён в DOM, путь — в title. Строки 44 px, расстояние индикатора до внешнего правого края 17 px (16 px padding + рамка).
6. Применение цвета — галочка рядом с HEX-полем. Валидный изменённый draft включает акцентный вариант; после применения кнопка становится quiet/disabled. Невалидный и эквивалентный каноническому цвету draft не отправляются. Доступное название и Enter сохранены. UI-тест проверил новое значение, применение, neutral-state и invalid-state; SSR-тест проверяет эквивалентный #abc для #AABBCC.

## Проверка

Полный прогон: 114/114. После последнего уточнения default viewport и явного inline-specimen — 11/11 целевых проверок feedback/form, включая новый тест портала. Сборка стенда и независимые production-сборки Next.js/Vite из пересобранного tgz прошли. 8 схем / 59 проверок planned fixtures прошли; это не проверка production release. Предупреждение о размере JS-чанка стенда сохраняется.

Браузер: EN/RU/VI × 320/768/1440 px — переполнения страницы нет, центры тумблеров совпадают с заголовками, цены $0/$16/$56, галочка неизменённого цвета disabled. На 320 px tooltip 280 px остаётся внутри экрана с полями; toast 288 px с 16 px по краям. В трёх языках показ/скрытие уведомления при неизменных данных формы даёт delta height=0.

Важно различать: загрузка примера меняет текст правого превью и может изменить естественную высоту его содержимого. Это отдельно записано в raw evidence; изоляционная проверка сравнивает уведомление при тех же данных, а не два разных набора текстов.
