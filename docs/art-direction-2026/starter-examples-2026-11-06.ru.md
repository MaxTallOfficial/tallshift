## Реализовано

- `/{locale}/library/press-button`: реальный счётчик, образцы pending/disabled, нативная ссылка, настройки цвета/анимации, код, запрос для ИИ, инструкция и ZIP.
- `/{locale}/library/content-tabs`: реальное переключение трёх разделов, настройки линии выбора/анимации, код, запрос, инструкция и ZIP. Полный API принимает 2–6 вкладок, поддерживает внешнее и внутреннее управление, обе ориентации и клавиатуру.
- Реестр выбирает демо и файлы по ID. Доступны три бесплатных локальных примера: A001/C001/C002; остальные 29 позиций остаются запланированными. Все девять бесплатных и 23 платных позиции сохраняют исходный состав и IDs.
- Главная, каталог, Starter, кабинет и EN-шаблон объясняют текущую готовность. Выбранный пример A001 на главной сохранён. Подборка больше не называет готовый C001 запланированным.
- Общая ссылка с настройками привязана к ID/версии, формат A001 совместим. Архив отменяется при смене настроек во время подготовки. Читаемая инструкция в запросе больше не зависит от имени A001.
- Произвольный цвет C001 получает фактически контрастную подпись. У C002 произвольный HEX меняет только линию; текст и рамка выбранной вкладки различимы независимо от него, forced colors переопределяет линию.

### Что исправлено по проверкам

Независимый reviewer обнаружил на desktop снимках разрыв «Заметная» и Expressive внутри слова. Автоматический тест ширины контейнера этого не замечал. В общей области настроек уменьшены горизонтальные отступы сегментов до системного шага 4 px и отключён перенос внутри слова; тексты и native radio semantics сохранены. В browser QA добавлена проверка каждого слова через Range, снимки всех трёх языков повторены, включая открытые настройки на 320/1440.

Первое ожидание QA об инструкции ошибочно требовало ID в тексте: renderer намеренно не выводит Markdown h1. Уточнено ожидание фактического имени компонента. Также переход браузерного теста на тот же адрес с новым hash не перезагружал документ и оставлял открытые настройки. Для проверки того, что получает адресат ссылки, тест теперь явно перезагружает shared URL. Эти неудачные попытки не считались пройденным браузерным результатом.

## Ограничения и статус

Это подключённые локальные примеры, не утверждённые пользователем коммерческие релизы. Реальные платежи, авторизация, заказы, права на платный код и платные скачивания не добавлялись. Пользовательских тестов с аудиторией 16–45 лет и проверки VI носителем не было. Редакторский и технический результат не являются пользовательским утверждением.

GitHub Actions и внешние проверки дизайна не запускались; commit/push этого этапа не выполнялись. Скриншоты и отчёты остаются в репозитории локально. Проверки страниц используют отдельный временный Chrome и разрешают только адрес проекта и встроенные data/blob/about; это фильтр запросов страницы, а не доказательство изоляции фоновых процессов всей ОС.

## Воспроизведение

Из `prototype`:

```sh
node --test --test-concurrency=2 tests/*.test.ts
npm run test:examples
npm run test:study
npm run build
npm run build:system
npm run check:design -- prototype/src/product
npm run check:design -- prototype/src/recipes
```

Перед браузером завершить тесты/сборки. Первый прогон после параллельных Vite-тестов не дождался `main h1`, при этом `pageerror` не было. После перезапуска dev server страницы открылись. Конфликт общего dependency cache — вероятное объяснение по логам повторной оптимизации, а не отдельно доказанная причина; ошибка не была засчитана успешной проверкой.

```sh
npm run dev -- --port 4173
HALLMARK_PUPPETEER=/tmp/tallshift-hallmark-runtime node scripts/verify-starter-examples.mjs
TALLSHIFT_QA_OUT=docs/art-direction-2026/evidence/starter-examples-2026-11-06/site-regression HALLMARK_PUPPETEER=/tmp/tallshift-hallmark-runtime node scripts/verify-product-copy.mjs
```

Временный путь Puppeteer относится к текущей машине. Скрипт общей регрессии поддерживает отдельный выходной каталог, чтобы не перезаписывать доказательства предыдущей версии в `copy-and-checkout-2026-11-06`. Прежние количества проверок не складываются с новыми и не объявляются проверкой последней версии.
