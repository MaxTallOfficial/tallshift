# Планшетная навигация · 06.11.2026

Запрос Max Tall: переделать неудачный планшетный бургер в продукте и дизайн-системе; объяснить ссылку «Попробовать кнопку». Это следующая версия для просмотра, без заявления о пользовательском утверждении.

## Что изменилось

На планшете продукт не прячет два основных раздела: от 768 px видны каталог, тарифы, язык, избранное и «Открыть демо». На 768–1023 px подпись избранного сворачивается в библиотечную иконку с полным доступным именем. На телефоне используется общий `SystemNavigationToggle`: иконка разделов Hugeicons Duotone Rounded, видимая подпись «Меню» и шеврон. Раскрытое состояние обозначено цветом, границей и `aria-expanded`.

В стенде дизайн-системы применены тот же toggle и компактный `SystemLocaleControl`. Его 12 разделов сворачиваются ниже 1024 px: на планшете панель состоит из двух колонок, ниже 600 px — из одной. Высота ограничена, последний пункт доступен через прокрутку и клавиатуру. При выборе раздела фокус переходит к заголовку. При изменении ширины фокус переводится с исчезающего элемента на видимый контроль.

Первая визуальная проверка показала перенос Tallshift в стенде на 320 px. Исправлены специфичность отступов и запрет переноса wordmark; в проверку добавлен контроль высоты надписи. Панель не закрывает выбор языка в шапке. Палитра, Manrope, маршруты и условия доступа сохранены.

## Тексты

Копирайтер проверил смысл переходов для первого посетителя и согласованность RU/EN/VI. «Попробовать кнопку» смешивало переход на страницу с действием внутри демо.

- Шапка: **Открыть демо**.
- Главная и бесплатное знакомство: **Посмотреть бесплатный пример**.
- Карточка: **Открыть демо и код**.
- Внутри примера: **Скопировать текст** — собственно действие кнопки.

Три первых действия открывают страницу рабочего бесплатного React-примера с настройками, исходником, промптом и инструкцией. Автоматического скачивания они не обещают. Название A001 — «Кнопка с откликом», State Relay остаётся техническим именем и частью неизменного URL.

## Проверка

Завершены [180 проверок раскладки продукта](evidence/tablet-navigation-2026-11-06/geometry.json) на 10 ширинах и 6 маршрутах в RU/EN/VI, а также [27 проверок шапки дизайн-системы и 13 групп поведения](evidence/tablet-navigation-2026-11-06/flows.json). Страницы не выбрасывали ошибок; внешних запросов страницы не было. Проверены Escape, внешний клик, раскрытие/переходы, оба направления смены ширины, фокус, языки с сохранением query/hash, forced colors и reduced motion. Геометрия относится к шапке и доступности её элементов, не ко всем образцам стенда.

Клавиатурный проход сначала обнаружил потерю фокуса при сужении окна: Chrome сбрасывал активный элемент до события смены breakpoint. Исправлено сохранением последнего фокуса внутри шапки только для восстановления при смене ширины. После исправления 13 групп повторно прошли. Неуспешный проход сохранён отдельно в `initial-run.json`; он не используется как успешный результат. Длинный первоначальный сеанс браузера также был прерван; окончательная проверка стенда создаёт отдельную вкладку для каждого случая.

- `npm test`: 145 из 145.
- `npm run build` и `npm run build:system`: прошли, включая типы общего компонента.
- [Защищённый статический Hallmark, продукт](evidence/tablet-navigation-2026-11-06/hallmark-product.txt): 0 FAIL / 0 REFLEX / 0 WARN, 15 файлов.
- [Весь каталог foundations](evidence/tablet-navigation-2026-11-06/hallmark-foundations.txt): 0 FAIL / 0 REFLEX, **13 WARN** в остальных образцах. Это не чистый автоматический вердикт для всей дизайн-системы. Два замечания к шагу отступов навигации исправлены.

Оставшиеся предупреждения: ширина пояснения типографики (25), структура заголовка EmptyState (54), локальный сценарий модального примера (70), кавычки в спецификации иконок (F1), числовая типографика состояния owned (F6), семь эвристик повторяющихся контейнеров образцов (F7), граница с тенью toast (F24). Они не скрыты и не объявлены исправленными этим проходом; навигационных файлов в списке больше нет.

Hallmark запускался только через закреплённую локальную обёртку с сетевым запретом ОС и очищенным окружением. Визуальные проверки — скрипт проекта, отдельный временный браузер, запросы только к адресу проекта. Upstream capture/render, личный браузер, Together AI и отправка владельцу скилла не использовались.
