# Проверка стенда арт-направления

Дата: 22 октября 2026. Объект: `art-direction/review.html`, foundations-кандидаты `0.1.0`. **Стиль и цвет не утверждены. Проверки стенда не подтверждают готовность всей production-системы.**

## Фактически выполнено

| Проверка | Итог |
| --- | --- |
| Сборка самостоятельного HTML | `node build.mjs`: CSS/JS и Manrope/Unbounded/Golos Text встроены в один файл; 18 наборов токенов сохранены отдельно |
| Контраст и роли | `node --test tests/*.test.mjs`: 3 группы passed. Для всех 18 сочетаний проверены text/secondary на background/surface, контур контролов, on-accent, ссылка, focus, hover, selected outline и семантические статусы. Проверена независимость status/geometry от акцента |
| Синтаксис | `node --check` для app, tokens и specimens: passed |
| Три направления | Все три переключаются; меняются типографика, материал, форма, токены и авторская геометрия. В консоли проверенного браузера error-записей не найдено |
| Авторское движение | В Material Signals кнопка переключает объём/элементы и название обратного действия; Type Foundry и Afterlight имеют отдельные рендереры. Нет постоянного render loop в покое |
| Поле/ошибка | Строка `ab` + Validate → aria-invalid=true; корректный текст снимает ошибку |
| Ожидание | Явный checkbox включает демонстрационный pending и disabled; снятие возвращает доступную кнопку. Действие не выдаётся за сетевую операцию |
| Keyboard tabs | ArrowRight перемещает фокус, Enter активирует вкладку Principles/«Правила» с aria-selected=true |
| Поиск | Несуществующий запрос скрывает все три образца; очистка возвращает их |
| Выбор/настройка | Switch меняет guides; Select выбирает compact; Slider ArrowRight меняет значение 45 → 50% |
| Tooltip/Disclosure | Tooltip доступен кликом/focus, закрывается Escape; native details раскрывается |
| Dialog | Native modal открывается; Escape закрывает и возвращает focus к исходной кнопке |
| Обратная связь | Сохранение выбранных образцов показывает реальный локальный toast; это память текущего сеанса, не аккаунт |
| Clipboard | Copy JSON вызвал реальную запись. Прочитанный JSON содержит текущий Acacia accent, правильный on-accent/selected outline и `candidate-not-approved` |
| Скачивание параметров | Через UI скачан formrift-material-berry-candidate.json; файл распарсен, direction/accent совпали, статус остался candidate-not-approved |
| RU/EN | Смена locale обновляет подписи и сохраняет введённое «Новая коллекция» |
| Off/reduce | Переключение Off обновляет MOTION/OFF. Динамическая эмуляция prefers-reduced-motion даёт MOTION/REDUCED; эмуляция затем сброшена |
| Responsive | EN для каждого из трёх направлений: 320/390/768 px без горизонтального overflow после исправлений. RU для всех трёх на 320 px также без горизонтального overflow; desktop осмотрен на 1440 px |

В процессе исправлены: переполнение типографического specimen на 320 px; min-content растяжение мобильного artboard; промежуточный контраст при crossfade всей темы; focus-тон тёмной поверхности, который проходил контраст с background, но не с surface. После исправлений повторены соответствующие проверки.

Проверка выполнялась во встроенном браузере Codex на Chromium, через локальный HTTP. Самостоятельная сборка проверена тем же способом. Автоматическое открытие `file://` запрещено URL-политикой инструмента и не выполнялось альтернативными способами; запуск файла с диска не включён в browser evidence. Файл не содержит внешних runtime-зависимостей: это отдельно проверяется по сборке и исходникам.

Не выполнены: полная матрица Safari/Firefox/реальных touch-устройств, screenreader audit, фактический zoom 200%/400%, аудит всех цветовых комбинаций внутри полупрозрачных декоративных слоёв, production performance/WCAG-аудит. Автоматические проверки пар токенов не означают соответствие всего интерфейса WCAG 2.2 AA. На стенде реализованы 14 семейств; для остальных из 44 пока заданы контракты.

## Повторение

Из `art-direction`:

```sh
node build.mjs
node --test tests/*.test.mjs
python3 -m http.server 4181 --bind 127.0.0.1
```

Открыть адрес Local в браузере. Для browser QA используется `review.html` или исходный `index.html`; после изменения самостоятельную сборку нужно пересобрать. Временный сервер останавливается после проверки.
