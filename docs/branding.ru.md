# Tallshift — название и правила именования

Утверждено владельцем 24 октября 2026. Автор: **Max Tall**.

| Объект | Имя |
|---|---|
| Продукт и сайт | **Tallshift** |
| Словесный знак в интерфейсе | **tallshift** |
| Авторская подпись | **by Max Tall** |
| Дизайн-система | **Tallshift UI** |
| Визуальное направление | **Afterlight Instrument**; сокращённо **Afterlight** |
| GitHub | **MaxTallOfficial/tallshift** |
| Локальный npm-пакет прототипа | **tallshift-local-prototype** |
| Экспорт токенов текущего стенда | **tallshift-ui-07.tokens.json** |

Tall связывает продукт с автором. Shift передаёт движение, смену состояний и адаптацию готового материала к своему проекту. Название охватывает компоненты, секции, анимации, исходники, промпты и инструкции.

В обычном тексте используется Tallshift, без вариантов TallShift / Tall Shift. В интерфейсе допускается строчный словесный знак tallshift. После имени не добавляются «рабочее имя» или «временное название».

Прежние Vibelock и Formrift сохраняются только в истории исследования, архивных артефактах и совместимости. Сохранённые HTML прошлых итераций, снимки и JSON с результатами проверок не переписываются задним числом: их байты относятся к первоначальным проверкам. Доступ к избранному старого прототипа сохраняется через чтение прежнего ключа localStorage; новые записи используют tallshift.

Эта смена имени не утверждает новый логотип, не меняет выбранные Manrope / Saffron Lighter / тёмную базу и не повышает статус готовности дизайн-системы. Домен, npm namespace и товарный знак пока не зарегистрированы этой задачей.

## Проверка изменения имени

Прототип, Afterlight study и Foundations собираются; 44 автоматических теста и 12 экспортных сценариев прошли. В браузере EN/RU/VI на ширине 320 px: словесный знак остаётся в строке, его hit area 44 px, высота шапки 80 px, горизонтального переполнения нет. Заголовок страницы — Tallshift UI, футер содержит by Max Tall. Реально скачанный `tallshift-ui-07.tokens.json` имеет формат `tallshift-system-token-graph`, 228 токенов и прежний статус `visual-review`.
