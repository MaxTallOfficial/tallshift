# BETA-19 · A001: подпись кнопки без иконок · 26.11.2026

Задача BETA-19 из дорожной карты `docs/roadmap/tallshift-roadmap-2026-11-26.ru.md` (ветка `claude/roadmap-a888b5`). Источник — п. 1.1 отчёта критика сайта `docs/reviews/user-critic-2026-11-26.ru.md` (ветка `claude/user-critic-066247`).

## Что было

На главной и на странице «Кнопка с индикатором выполнения» подпись кнопки рвалась по 1–3 буквы: «C/op/y/te/xt», «Ск/оп/ир/ов/ат/ь», «Sa/o/ch/ép». То же получал каждый, кто скачивал пример.

## Причина (перепроверена по коду)

- Строка «иконка + подпись» (`.buttonContent` в `AfterlightExample.module.css`) была сеткой с постоянной первой колонкой 37 px (30 px на узких экранах).
- Иконки — необязательный слот: блок иконок выводится, только если передан `renderStateIcon`. Без него подпись становилась первым элементом сетки и попадала в колонку 37 px, а `overflow-wrap: anywhere` резал слова.
- Без иконок пример показывают окно примера на tallshift.com (`preview/main.tsx`) и выдаваемый `SelectedExample.tsx` (ZIP, вкладка «Код», запрос для ИИ). В локальном режиме сайта иконки передаются, поэтому при разработке ошибка не была видна.

## Что изменено

- `prototype/src/study/AfterlightExample.module.css`, только раскладка строки подписи:
  - `.buttonContent` — `display: flex` вместо сетки с колонкой под иконку, в том числе на узких экранах и в узком контейнере;
  - `.iconStack` — `flex: none`: место под иконку появляется, только когда иконки переданы;
  - `.labelStack` — `flex: 1 1 0; min-width: 0; grid-template-columns: minmax(0, 1fr)`: подпись занимает всю оставшуюся ширину;
  - `.labelStack > span` — `overflow-wrap: break-word` вместо `anywhere`: перенос только между словами. Слово режется, лишь если оно одно шире всей кнопки.
- Разметка, тексты, цвета и анимация не менялись. Тот же CSS уходит в демо, «Код», запрос для ИИ и ZIP.
- Новый тест `prototype/tests/state-relay-label.test.ts`, 4 проверки: разметка без иконок и с иконками в EN/RU/VI; правила CSS — в строке подписи нет постоянной колонки, слова не режутся по слогам; скачиваемый `SelectedExample.tsx` идёт без иконок и с проверенным CSS. На старом CSS тест падает с сообщением «icons are optional flex items, not a fixed grid column».

**Правило.** Необязательный слот, например иконка от host-renderer, не занимает постоянную колонку сетки: без слота туда попадёт текст. Для подписей кнопок не использовать `overflow-wrap: anywhere` и `word-break: break-all`, только `break-word` в колонке `minmax(0, 1fr)`. Пример проверять с иконками и без: выдаваемый код идёт без иконок.

**Как мерили в браузере.** В каждом случае 5 подписей: 4 состояния кнопки и режим «Показать ошибку». Проверка: ни одно слово не разорвано между строками (`Range.getClientRects`), текст не выходит за кнопку, иконка (если есть) стоит слева от подписи.

Ширины взяты с локальной копии сайта в боевом режиме (Next + отдельное окно примера, как на tallshift.com): при 1440 px окно примера 553 px на главной и 896 px на странице примера; при 768 px — 672 и 720; при 320 px — 256 и 288. Добавлены кнопки ширины 640 и 320.

- Настоящая сборка окна примера, управление по протоколу сайта: EN/RU/VI × 8 ширин = 24.
- То же окно из исходников без иконок и с иконками: 24 + 24, цифры совпали со сборкой.
- Страницы локального сайта с иконками, главная и страница примера: 320/768/1440 × EN/RU/VI × 2 = 18.
- Файлы из настоящего ZIP без иконок, простая страница, системный шрифт: EN/RU/VI × 256/288/320/768/1440 = 15.
- Контроль: тот же скрипт на старом CSS нашёл разорванные слова во всех 6 случаях (EN/RU/VI × 288/553). Значит, проверка ловит именно эту ошибку.
- На 256–288 px подписи RU/VI переносятся на вторую строку между словами — так и задумано.
- Клавиатура (RU, версия из ZIP): Tab ставит видимую рамку фокуса на кнопку, Enter запускает действие, фокус остаётся на кнопке.

## Что не проверено

- Скриншоты и оценка на глаз: панель браузера была скрыта, раскладку проверял только измерением.
- Сам tallshift.com: исправление не выложено, push и деплой — только с «да» Max Tall. После выкладки попросить `user-critic` перепроверить п. 1.1.
- Safari и Firefox, forced colors и reduced motion: в доступном браузере нет эмуляции. Правка не трогает цвета и анимацию.
- Успешное копирование: в скрытой вкладке браузер запрещает запись в буфер обмена. Путь с ошибкой отработал.
- `npm run test:examples:next` (настоящий Next-проект в браузере) не запускал: он берёт puppeteer из окружения Hallmark, а правила проекта разрешают только `check:design`.
- Старый компонент `recipe-exports/state-relay/Example.tsx` и `src/StateRelay.module.css` устроен так же: колонка 26 px под необязательные иконки. На сайте и в ZIP он не выдаётся, поэтому не менял. Если его начнут выдавать — исправить так же.
- Тексты не менялись, поэтому копирайтер не подключался.
