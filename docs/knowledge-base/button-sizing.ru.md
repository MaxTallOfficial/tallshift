# KB-UI-001 · Размер кнопки зависит от её роли в композиции

25 октября 2026. Правило задано Max Tall при проверке Tallshift: одинаковый размер всех кнопок на десктопе не является универсальным требованием. Отдельно стоящая служебная кнопка с иконкой не должна занимать столько же места, сколько основное действие. Числовые размеры ниже — текущая реализация для визуальной проверки.

## Выбор варианта

| Контекст | Вариант | Десктоп | Телефон / coarse pointer |
| --- | --- | --- | --- |
| Иконка рядом с обычными кнопками, пагинацией, табами в общей панели действий | `density="toolbar"` (по умолчанию) | 52 × 52 px | 48 × 48 px |
| Самостоятельная подсказка, информация о файле, закрытие окна/уведомления, отдельная группа служебных иконок | `density="compact"` | 36 × 36 px | 44 × 44 px |

Если устройство сообщает coarse pointer при широкой области просмотра, compact увеличивается до 44 px. Видимая рамка совпадает с областью нажатия. Иконка остаётся 20 px; для небольшого крестика допускается 16 px. Уменьшать область нажатия на сенсорном экране до 36 px нельзя.

## Обязательные правила композиции

- В одной панели основные кнопки, табы и сегментированные переключатели имеют одинаковую внешнюю высоту с учётом рамок и внутренних отступов.
- Компактность выбирают явно по роли кнопки. Не определять её по соседним DOM-элементам и не уменьшать все иконочные кнопки автоматически.
- Отдельный служебный элемент может быть меньше основных кнопок. Его выравнивают по центру своей строки или заголовка, а не растягивают для заполнения свободного пространства.
- Иконочная кнопка имеет лёгкую нейтральную рамку, прозрачный фон, видимый hover/focus, доступное название и центрированную иконку. Не компенсировать размеры смещением SVG.
- Кнопка информации без текста содержит только `i`, без стрелки. Кнопка меню действий содержит понятный текст и стрелку раскрытия.
- `size="small"/"large"` сохранены для совместимости; новые экраны используют контекстный `density` и адаптивную шкалу. Не смешивать произвольные размеры в одной основной панели.

## Примеры

```tsx
// Самостоятельная информация / закрытие: compact.
<SystemIconButton density="compact" icon="info" label="About this file" />
// Рядом с обычными кнопками: общая высота панели.
<SystemIconButton density="toolbar" icon="replay" label="Reset preview" />
```

Реализация: `SystemIconButton.tsx`, `system-button.css`, `system-control-metrics.css`. Панель исходников использует те же размеры compact для кнопки информации. Договорённость уточняет прежнее правило одинаковой адаптивной высоты, а не отменяет его для основных панелей.
