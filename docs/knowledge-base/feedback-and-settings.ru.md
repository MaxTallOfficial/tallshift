# KB-UI-003 · Устойчивая композиция настроек и обратной связи

Правки Max Tall, 26 октября 2026. Использовать при дальнейшей разработке.

1. Результаты коротких действий (сохранено, очищено, пример загружен, файл скопирован) — в общей очереди уведомлений в правом нижнем углу. Они не меняют размеры форм, карточек и превью. Общий host складывает сообщения разных компонентов, не накладывает их друг на друга. Не переводить сюда ошибки полей: они остаются рядом с полем. `SystemToastRegion` по умолчанию использует viewport. Inline-очередь разрешена только как явно выбранный specimen/встроенный журнал.
2. Tooltip с пояснением — максимум 280 px, на телефоне не шире viewport минус 24 px. Нормальный перенос строк, длинные токены разбиваются, окно не выходит за экран. Структурированный popover не подменять tooltip: у них разное поведение и семантика.
3. Тумблер расположен по центру строки заголовка. Описание, ожидание и ошибка находятся ниже и не сдвигают его центр. Длинное описание не меняет положение переключателя относительно заголовка.
4. Список файлов — отдельный спокойный контейнер. Название в одну строку с многоточием; расширение остаётся видимым, включая .module.css. Полное имя доступно в DOM и title; формат не теряется при выборе. Индикатор имеет 16 px внутреннего отступа от правого края. Убрать лишний разделитель над деревом.
5. Применение цвета — кнопка с галочкой рядом с HEX-полем. Акцент только для валидного значения, отличного от применённого. После применения — нейтральная и disabled; повтор того же цвета не отправляет изменение. Невалидный ввод остаётся локальным и подсвечивает ошибку. Кнопка сохраняет доступное название, Enter поддерживается.

## 27.10.2026 · Не прятать пояснение за раскрытием

Короткая информация о хранении черновика, составе локального примера и разрешённом использовании кода видна сразу рядом с контекстом. Отдельные кнопки «Где хранится черновик»/«Состав пакета», за которыми только предложение-подсказка, исключены. Hover-подпись компактной иконки может дублировать доступное имя; она не заменяет существенные условия. Меню предназначено для выбора или действия; popover — для реальных данных выбранного объекта, например пути, типа и размера файла. Не оставлять раскрытие «на будущее».
