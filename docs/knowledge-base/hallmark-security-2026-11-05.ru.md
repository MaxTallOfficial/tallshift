# Hallmark: локальный режим без отправки владельцу

Проверка от **5 ноября 2026**, установленный Hallmark **2.0.0**. Требование Max Tall: ничего из проекта не отправлять владельцу скилла. Проверены локальные инструкции, скрипты, сетевые вызовы, работа с окружением, файлами и браузером. Зафиксированы контрольные суммы 118 текстовых файлов в [манифесте](../../.hallmark/security.json).

В проверенных исходниках не обнаружена автоматическая отправка отчётов владельцу. При этом наличие отдельной генерации через Together AI означает, что весь скилл нельзя считать полностью офлайн без ограничений. Эти сетевые возможности в текущем проходе не запускались.

## Технические ограничения

[hallmark-offline.mjs](../../prototype/scripts/hallmark-offline.mjs) запускает только статический checker с фиксированными аргументами. Перед запуском сверяет SHA-256 проверенных файлов. Процесс получает только PATH, LANG и TZ; ключи из окружения не наследуются. Политика macOS запрещает все сетевые операции, а Node permission model разрешает чтение только проверенных файлов скилла, `prototype/src` и `prototype/package.json`. Запись и создание дочерних процессов не разрешены. Произвольные флаги, URL и пути вне исходников отвергаются. Если защита недоступна или файл скилла изменён, запуск прекращается.

Визуальная проверка [verify-product-hallmark.mjs](../../prototype/scripts/verify-product-hallmark.mjs) — отдельный код проекта. Он использует временный профиль Chrome и перехватывает запросы страницы: разрешён только `http://127.0.0.1:4173` и встроенные data/blob/about, внешние запросы отменяются. Это ограничение запросов страницы, а не изоляция всей фоновой активности Chrome на уровне ОС. Скрипты Hallmark в браузерной проверке не выполняются.

## Проверено

- Защищённый checker успешно завершён: **0 FAIL / 0 REFLEX / 0 WARN**.
- Сетевое ограничение проверено без обращения к внешнему серверу: создание локального сетевого сокета запрещено с `EPERM`.
- `--render` и путь `docs` отвергаются обёрткой до запуска checker.
- При первом запуске доступ к неразрешённому `prototype/package.json` был запрещён. Затем добавлено точечное разрешение только на этот файл; доступ ко всему репозиторию не открывался.
- Визуальные результаты и список заблокированных запросов фиксируются в [checks.json](../art-direction-2026/evidence/product-hallmark-2026-11-05/checks.json).

Аудит относится к указанной локальной версии и способу запуска. Он не является проверкой всей ОС или работы самого Codex. Для Hallmark разрешённый процесс не имеет сетевого канала отправки владельцу; политика проекта запрещает передавать эти данные и через другие инструменты.
