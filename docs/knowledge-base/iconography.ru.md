# KB-UI-005 · Иконки из библиотеки

Решение Max Tall от 26.10.2026: все интерфейсные иконки, включая стрелки и раскрытия, брать из готового набора. Для Tallshift утверждён **Hugeicons Duotone Rounded**.

Единственная точка подключения — `SystemIcon`. Для нового значения расширяем его тип и реестр импортом из `@hugeicons-pro/core-duotone-rounded`. Для native details используем `SystemDisclosureIcon`, скрывая браузерный marker: закрытая/открытая стрелки остаются библиотечными. CSS может позиционировать и переключать библиотечные иконки, но не рисовать им геометрию.

Не допускаются рукописные `<svg>/<path>` для UI-глифов, стрелки из border/clip-path, псевдоэлементы с `content:'›'/'+'/'−'`, текстовые «галочки» и нативный треугольник вместо библиотечного раскрытия. Символы в обычных текстовых пояснениях клавиш или схемах данных не являются кнопочными иконками.

Размеры: 16/20/24 px. Поддерживаемые stroke — 1.5 px; сохраняются native fill и прозрачность второго тона. Кнопки задают область нажатия и padding отдельно; иконка центрируется, рядом с текстом сохраняется системный gap. У кнопки обязательное доступное имя, декоративный glyph aria-hidden.

Платформа передаёт свои иконки в переносимое демо через host-renderer. Из выдаваемых исходников не получается копия закрытой библиотеки: renderer необязателен, поведение и текстовые состояния доступны без него. Новый проект использует собственную общую обёртку с тем же принципом.

Правило также закреплено в корневом AGENTS.md и личных инструкциях Codex для последующих проектов.
