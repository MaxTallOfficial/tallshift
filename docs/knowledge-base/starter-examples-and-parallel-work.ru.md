# KB-UI-011 · Бесплатные примеры и параллельная разработка

Дата: **06.11.2026**. По запросу Max Tall основной агент запустил двух разработчиков и отдельного продуктового копирайтера. Первый независимый этап — C001 и C002: у них нет зависимостей от других позиций, а сами они нужны будущим блокам страниц. Серверные покупки требуют отдельных решений и не включены в этот этап.

## Разделение работы

- Агент C001 меняет только `prototype/src/recipes/press-button/` и свои проверки.
- Агент C002 меняет только `prototype/src/recipes/content-tabs/` и свои проверки.
- Копирайтер проверяет фактические демо, инструкции, требования ИИ, RU/EN/VI и связанные публичные страницы. Общие тексты и [редакторский журнал](copy-review.ru.md) принадлежат ему; замечания к компонентам он передаёт их авторам. Дополнительных агентов не создаёт.
- Основной агент соединяет общую рабочую область, реестр, экспорт и ссылки, проверяет поведение, комплект и реальную вёрстку после окончательной редактуры. Общие файлы не редактируются одновременно разными исполнителями.

Первый запуск трёх агентов завершился до работы из-за лимита использования. После прямого «продолжай» задачи повторно запущены и выполнены. Не считать неудачный запуск выполненной разработкой или редакторской проверкой.

## Что добавлено

**C001 — «Кнопка с эффектами наведения и нажатия» / Press Button.** Нативные button/link, размеры sm/md/lg с целью не меньше 44 px, цвет, радиус, состояния pending/disabled, motion/off/reduce и необязательный icon slot. Реальное действие демо увеличивает счётчик; отдельно подписанные образцы выполнения/недоступности не запускают операцию. Локальная ссылка ведёт к пояснению, не загружает сайт внутрь iframe. Собственный обработчик и настоящее состояние операции задаёт проект интегратора. Заблокированная ссылка временно не имеет href; aria-disabled сохраняет фокус и предотвращает повторную активацию. Цвет текста на произвольном фоне выбирается по фактическому sRGB-контрасту не ниже 4.5:1.

**C002 — «Вкладки для переключения содержимого» / Content Tabs.** От двух до шести разделов, controlled/uncontrolled API, горизонтальная/вертикальная ориентация, стрелки/Home/End/Tab, уникальные связанные IDs нескольких экземпляров. Скрытые панели остаются mounted, но имеют hidden и не получают фокус. На узкой ширине прокручивается полоса вкладок. Произвольный цвет меняет только линию выбора; выбранная вкладка сохраняет читаемый текст, поверхность и рамку. Off/reduce сразу меняют выбранную панель и положение линии без анимации. Для forced colors цвет линии переопределяется системой, несмотря на пользовательский HEX.

Публичные поля обеих страниц: тип React-проекта, цвет, режим и длительность анимации. Остальные свойства — документированный кодовый API, а не якобы доступные поля настройки. Состояние демо и выбранный раздел не выдаются за сохранённую конфигурацию установки.

## Единая выдача

- `material-recipes.tsx` выбирает демо и генератор по ID. A001 сохраняет существующий Afterlight и его исходники. Новые страницы не вызывают экспорт State Relay.
- `available-examples.ts` хранит IDs подключённых локальных примеров отдельно от исторического планового `catalog.json`. Проверка экспорта сопоставляет доступность всех 32 карточек с подключёнными демо/генераторами. Это локальная готовность примера, не production release в плановом каталоге.
- `recipes/shared/example-recipe.ts` генерирует выбранный entry, настройки, схему, manifest, три языка инструкций, лицензию и ZIP. `?raw` берёт те же локальные файлы, которые монтируются в превью. Все локальные зависимости входят в комплект; приватных Pro paths, шрифтов, изображений и новых runtime-пакетов в нём нет.
- Скопированный запрос включает точные исходники, настройки и инструкцию. Локализованное функциональное имя идёт первым. Контекст проекта включается только по выбору пользователя и не попадает в ссылку. Автоматической отправки в ИИ нет.
- ZIP воспроизводим для одинакового выбора, manifest перечисляет реальный состав, SHA-256 покрывает все файлы кроме `checksums.json`.
- Ссылка с настройками проверяет ID и версии своего примера. Старый формат A001 совместим; C001 не принимает ссылку A001/C002. Изменение настроек во время подготовки ZIP отменяет выдачу устаревшего результата.
- `PromptDocument` получает читаемую инструкцию из фактически включённого INSTALL, без жёсткой привязки к заголовку A001.

Принятия новых страниц пользователем и исследования с представителями ЦА/носителем VI пока нет.
