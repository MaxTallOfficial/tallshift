# ТЗ v0.3 — анимации сайта и отдельная motion-библиотека

> **Архив.** Актуальная каноническая редакция: [единое ТЗ v1.0](product-spec-v1.0.ru.md). Содержание ниже сохранено как история и не задаёт текущий scope, цены или готовность продукта.

Статус: дополнение к [подробному ТЗ v0.2](product-spec-v0.2.ru.md), разработка ещё не начата. Новый запрос пользователя: авторские UI-анимации нашего сайта и отдельный раздел анимаций по категориям, с промптом, готовым скриптом и инструкцией.

Подтверждённые ранее решения сохраняются: публичный сервис; React + TypeScript; Next.js/Vite; RU/EN; готовый код и адаптационный prompt. Количество и названия новых материалов, распределение Free/Pro и очередь реализации ниже — предлагаемый точный объём дополнения.

## 1. Два результата

**Анимации самой платформы:** связанный характер движения при выборе, настройке и получении кода. Это часть дизайна нашего сайта и демонстрация качества продукта.

**Раздел «Анимации / Animations»:** самостоятельные переиспользуемые рецепты, которые пользователь применяет к своему интерфейсу. Каждый поставляется как demo + script + prompt + инструкция. Готовые секции не являются обязательным условием их использования.

«Авторские» означает собственную постановку, графику, исходники и систему поведения. Глобальная уникальность общих fade/FLIP/underline и исключительность идеи не заявляются.

## 5. Формат получения

У каждой animation-записи:

1. Живой пример с явным trigger и безопасной авторской разметкой.
2. Готовый локальный hook/controller на TypeScript, CSS и полный React Example для Next/Vite.
3. Preserve/adapt prompt на RU/EN с теми же файлами и config.
4. INSTALL.ru/en.md: markup, зависимости, подключение, настройки, cleanup, SSR, reduce, keyboard/touch, ошибки и проверка.
5. Manifest со script entry, state machine, interruption/focus/cleanup policy и поддержанными capabilities.
6. ZIP/файлы, checksums и лицензии по прежнему контракту выдачи.

Framework-free JavaScript может появиться как сборка переносимого TS-controller конкретного recipe после отдельной проверки. Он не обещается автоматически всем 32 материалам. «Скрипт» не означает ссылку на runtime нашего CDN или возможность посетителю исполнять произвольный JS в Studio.

Навигация: новый пункт «Анимации», routes `/{locale}/animations` и `/{locale}/animations/{categorySlug}`; canonical detail остаётся `/{locale}/library/{itemSlug}`. Общий каталог группирует E и A в пользовательский раздел «Анимации», сохраняя разные types внутри registry. В Studio остаются режимы Демо/Настройки/Код/Для AI; инструкция доступна отдельным действием/якорем.

Новые Free A001/A003/A006 имеют тот же стандарт качества и полный комплект. Исходники E001 также Free. У Pro закрыт script/source и prompt с исходниками, а demo, параметры и условия открыты.

Предлагается новый **PACK-MOTION**: E002, E003, E004, A002, A004, A005, A007, A008 — 8 Pro, из них только 5 новые. Ранее полученные права на E действуют и здесь. Новая цена Motion пока не назначена.

У трёх тематических packs сохраняется состав по 6. Новый BUNDLE-LAUNCH revision 0.3 объединяет четыре набора: **18 + 8 − 3 пересекающихся E = 23 Pro**. Прежний snapshot 18 не меняется; новые IDs не включаются молча в старое окно обновлений. Ценовая гипотеза $59 для прежнего состава не переносится на расширенный bundle автоматически. Актуальный реестр содержит 6 предложений: Free, четыре paid packs, bundle.

Продуктовые правила 12 месяцев обновлений, повторного скачивания, security remediation, overlap grants и возвратов наследуются из v0.2. При переходе в Motion/bundle quote учитывает реально имеющиеся права; техническая возможность удалить уже скопированный код не обещается.

Все новые release требуют прежних QA/ИБ gates и новых AN/SITE-M критериев. Нужны быстрая отмена/повторный ввод, Strict Mode, два экземпляра, resize/font/locale changes, Off/reduce в текущей сессии, focus и реальные исходники из ZIP.

Счётчик prompt families становится **32 × 2 режима × 2 языка = 128**, с двумя React targets — **256 комбинаций contract checks**. В animation-разделе 48 families/96 target cases — подмножество этих чисел. Это план будущей проверки, не выполненные тесты и не количество товаров. Дополнительные JS adapters потребуют своей проверки и не маскируются под уже выполненные 256.

Следующий предметный этап — motion-прототип одного пути выбора/настройки/получения и один полноценный recipe A001. Самостоятельные анимации выпускаются после проверки скрипта и инструкции, а не после записи названия в каталог.
