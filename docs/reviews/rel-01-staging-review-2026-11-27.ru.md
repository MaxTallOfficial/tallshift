## Три отдельных вопроса задачи
1. **«Сервер превью не настроен».** Текст `off` из `RemotePreview.tsx` показывается только если адрес превью не вшит в сборку (`!configured`), а не по таймеру. На тесте адрес вшит, надпись не появилась ни разу ни в HTML, ни в живой странице. На медленной сети код после 5–10 с показывает «Превью не ответило. Попробуйте загрузить ещё раз» с кнопкой «Загрузить снова» — это честно. Реальную медленную сеть не воспроизводил. Статус: исправлено по коду.
2. **Подпись кнопки A001.** `/vi/library/state-relay`, 375 px: «Sao chép văn bản» в одну строку, шаги и кнопки без разрыва. RU на главной 1440: «Скопировать текст» целиком. Статус: ок (EN на 375 не смотрел).
3. **Не обещает ли витрина продаж.** Pricing RU: «Продажи ещё не открыты; состав и цены наборов можно посмотреть», кнопки «Посмотреть состав», а не «Купить». Платный пример (`/ru/library/product-demo-hero`): «Этот пример пока не готов… Работающего примера и файлов пока нет». Каталог: «Можно использовать: 9 / В плане: 23». Витрина честная.

## Важное
1. **`/ru/library/*` в HTML пустой.** Для `curl`, поисковиков и разработчика «Просмотр кода страницы» страницы отдают только «Загружаем страницу…» — содержимое рисует клиент. На медленной сети пользователь долго видит пустую страницу. Адрес: все страницы, RU/EN/VI, 1440/375.
2. **Серый пустой блок превью после «готово».** `/vi/library/state-relay`, 375: через ~3,5 с превью уже не «Загружаем», но ещё пустой серый прямоугольник, пример проявился ещё через несколько секунд. Человек может решить, что сломано. Нужен скелет/подпись до первого кадра.
3. **Страница о данных — язык для разработчика, не для человека без терминов.** `/ru/privacy` (то же EN/VI), 1440: «хеш scrypt», «SHA-256», «user-agent», «D1», «localStorage» без простого пояснения. Первый клиент спросит «что это значит для меня». Достаточно одной фразы в начале «Пароль нельзя прочитать даже нам; есть только его необратимая отметка».
4. **Обещание, которого нельзя проверить.** `/ru/privacy`: «Войдите и откройте «Кабинет» → «Удалить аккаунт»». Я не вошёл и не подтвердил, что такой пункт существует и работает; `/ru/account` отдаёт 200. Перед main владельцу нужно один раз пройти этот путь на тесте.
5. **Pricing пишет в настоящем времени о неработающем.** `/ru/pricing`, 1440: «Покупка для одного человека… Нельзя перепродавать», «Что происходит после покупки», «Как считается доплата», «Как учитываются прежние покупки» при отсутствии покупок. Вверху оговорка есть, но ниже читается как действующий договор. Лучше пометить «Условия на запуск продаж» и скрыть доплату до открытия продаж. Карточки «Платный», цена «16 $ / 39 $» рядом с оговоркой допустимы.
6. **«Открыть пример» в шапке и «Открыть каталог» на главной ведут в разные места?** Шапка (все страницы, 1440): жёлтая кнопка «Открыть пример» без пояснения какой пример. На 375 шапка превращается в «Меню». Нужно уточнить цель.

## Мелочи
- Главная и каталог, RU 1440: в названиях английские имена в скобках «(State Relay)», «Press Button», «Content Reveal» — вторичны, но на карточке стоят под заголовком; по AGENTS.md допустимо, для новичка шум.
- Каталог, 1440: у карточек State Relay и Line Assemble категория «Анимации» стоит выше кнопки на разной высоте; категории в карточках выровнены не по одной линии.
- Pricing, 1440: бейдж «Для запуска продукта» перекрывает верхнюю рамку карточки Product; «Editorial, Playful и UI Motion … по $16» висит одиноко под раскрывашкой «Как считается доплата».
- Главная, 1440: «Девять бесплатных примеров уже можно скачать без регистрации» — мелкий и тусклый, а это главное обещание.
- Запрос для ИИ на главной содержит внутренние обозначения «A001@0.1.0-prototype», «latest-ticket» — для ИИ годится, для человека, который читает запрос перед вставкой, это непонятный шум.
- Название организации на странице данных: «Юридические реквизиты будут добавлены позже» — честно, но публично это слабое место.
