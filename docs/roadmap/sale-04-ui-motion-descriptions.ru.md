# SALE-04 · Описания платных анимаций UI Motion · 27.11.2026

Направление для приёмки Max Tall. Статус: дизайнер и копирайтер проверили, правки внесены; Max Tall 27.11 принял направление и велел начинать разработку после полной проверки текстов копирайтером. Платный код — только в приватном `tallshift-paid`.

Набор UI Motion по решению 27.11: E002 (делает сессия набора Product) + 7 позиций ниже. С ними все восемь категорий анимаций получают хотя бы один пример (раздел 6 дорожной карты).

**Как читать карточку.** «Простой слой» — что видит человек и куда это поставить; для тех, кто собирает сайт с ИИ-редактором. «Для разработчика» — что берёт на себя код. «Зачем платить» — почему это полезнее того, что есть бесплатно или пишется за вечер.

**Публичные названия.** По совету копирайтера предлагаем понятные названия вместо терминов ТЗ; название из ТЗ и ID остаются вторичными (правило AGENTS.md). Это часть направления на «да» Max Tall. Названия сверены с каталогом (`prototype/src/product/catalog-data.ts`), где у этих ID уже есть подписи: E003, A002 и A008 совпадают с каталогом; у E004, A004, A005 и A007 предложены другие названия, и при разработке каталог нужно обновить вместе со страницей (RU/EN/VI и описание), чтобы карточка и страница назывались одинаково.

**Общее для всех семи:** React + TypeScript, CSS Modules, без зависимостей; демо — интерфейсная сцена без фото; цвета берутся из сайта или из значений по умолчанию (тёмная поверхность и шафрановый акцент, без второй темы ради демо); если у посетителя включено уменьшение движения или эффект выключен, содержимое сразу видно и работает; запрос для ИИ, инструкция RU/EN/VI, manifest, SHA-256 и ZIP — из одних настроек. Работа в чистых Next.js и Vite — критерий приёмки каждой позиции, а не обещание в тексте.

## 1. E003 · Мягкий градиентный фон / Soft gradient background

- **Категория:** Фоны и курсор.
- **Простой слой:** спокойный цветной фон за одним блоком страницы — например за первым экраном сайта или за блоком с главной кнопкой. Цвета медленно перетекают за текстом. Кнопка «Пауза» входит в код: посетитель вашего сайта может остановить движение. Цвета по умолчанию подобраны так, чтобы текст поверх читался; если ставите свои, проверьте, что текст по-прежнему хорошо виден.
- **Для разработчика:** 3–4 слоя CSS-градиентов внутри ограниченного контейнера, без WebGL и canvas; движение — только `transform`; пауза вне экрана и в скрытой вкладке; нативная кнопка Pause/Resume входит в экспорт; фон `aria-hidden`; статичная версия при `prefers-reduced-motion`.
- **Зачем платить:** фонов среди бесплатных примеров нет. Типичный градиент из интернета либо стоит на месте, либо перерисовывает весь экран и тратит батарею. Здесь уже сделано то, что обычно забывают: кнопка паузы, остановка, когда блок не виден, цвета сайта.
- **Демо:** блок с заголовком и кнопкой на анимированном фоне; кнопка «Пауза» / «Продолжить».
- **Настройки:** основной цвет; анимация — выключена / спокойная (очень медленный небольшой сдвиг) / выразительная (медленнее и шире); плавность остановки по «Паузе» (0–600 мс).
- **Чем не является:** не фон на всю страницу и не генератор градиентов.

## 2. E004 · Подсветка за курсором / Cursor spotlight (ТЗ: Pointer Spotlight)

- **Категория:** Фоны и курсор.
- **Простой слой:** мягкое пятно света следует за курсором внутри карточки — например в блоке возможностей или услуг. На телефоне курсора нет, поэтому подсветка стоит на месте. Подсветка лежит под содержимым: кнопки нажимаются и текст выделяется как обычно.
- **Для разработчика:** позиция через CSS-переменные, обновление не чаще кадра (`requestAnimationFrame`); слушатели только на своём блоке и только пока курсор внутри; слой `pointer-events: none`; на касаниях и при уменьшении движения — статичная подсветка; при фокусе с клавиатуры подсвечивается карточка целиком; полная очистка при размонтировании.
- **Зачем платить:** типичный копипаст вешает слушатель на всё окно и пересчитывает стили на каждое движение мыши. Здесь — только свой блок, не чаще одного обновления за кадр и замена эффекта для клавиатуры и телефона.
- **Демо:** три карточки возможностей продукта (не тарифы), у каждой своя подсветка; на 375 — в одну колонку.
- **Настройки:** цвет, анимация (спокойная — небольшое пятно, выразительная — крупнее и ярче), длительность; размер и сила — свойства `size` и `intensity` в коде.
- **Чем не является:** не «хвост» за курсором и не эффект на всю страницу.

## 3. A002 · Плавная смена содержимого / Smooth content switching (ТЗ: Context Bridge)

- **Категория:** Навигация и переходы.
- **Простой слой:** когда человек переключает вкладку, шаг или фильтр внутри блока, старое содержимое уходит, новое появляется на том же месте, а высота блока меняется плавно — текст ниже не прыгает. Это не сами вкладки: эффект добавляется к вкладкам, шагам или фильтрам, которые уже есть на сайте.
- **Для разработчика:** обёртка над содержимым, которое уже переключают ваши вкладки (например, бесплатный пример «Вкладки для переключения содержимого»): `current → incoming-ready → transition → current`. Новое содержимое показывается, когда оно готово, в том числе после загрузки; при быстрых переключениях побеждает последнее; высота анимируется по измерению; фокус передаётся по правилам приложения. Если выбор вкладки записан в адресе страницы, кнопки «Назад/Вперёд» браузера не ждут анимации.
- **Зачем платить:** бесплатные «Вкладки для переключения содержимого» меняют содержимое мгновенно. Переход ломается именно в неудобных случаях — загрузка ещё идёт, человек жмёт быстро, разделы разной высоты; здесь эти случаи решены.
- **Демо:** карточка «Возможности / Отзывы / Вопросы» с содержимым разной высоты и имитацией загрузки.
- **Настройки:** вид перехода (сдвиг / растворение), длительность, анимация вкл/выкл.
- **Чем не является:** не новые вкладки, не навигация по сайту и не переход между страницами.

## 4. A004 · Раскрытие карточки / Expanding card (ТЗ: Focus Plane)

- **Категория:** Карточки и медиа.
- **Простой слой:** нажали на карточку — она плавно разворачивается в подробный вид на том же месте; кнопка «Назад к проектам» внутри блока сворачивает её обратно. Человек видит, откуда пришёл. Подходит для списка проектов, товаров или статей; карточки и подробности — ваши.
- **Для разработчика:** переход геометрии `idle → target-ready → morph → settled → return` по измерениям (FLIP), без копии, которая «улетает» при прокрутке или изменении размера окна; если подробный вид не готов — обычное открытие без анимации; кнопка возврата доступна с клавиатуры, фокус возвращается на исходную карточку.
- **Зачем платить:** бесплатные карточки и список не связывают «до» и «после». Связный переход часто просят, а самодельные версии ломаются на прокрутке, медленной загрузке и быстром повторном клике.
- **Демо:** 4–6 карточек проектов с разными мини-схемами интерфейса на обложке (не одинаковые плашки) → подробный вид с описанием и кнопкой «Назад к проектам». Подпись не «Назад», чтобы её не путали с кнопкой браузера.
- **Настройки:** длительность и анимация; скругление углов — в коде (`radius`).
- **Чем не является:** не галерея для просмотра фото и не готовая карточка проекта с текстом и ссылкой.

## 5. A005 · Выдвижная панель / Slide-out panel (ТЗ: Edge Unfold)

- **Категория:** Панели и меню.
- **Простой слой:** панель выезжает сбоку, а на телефоне — снизу; подходит для меню, фильтров, корзины или настроек. Закрывается кнопкой, клавишей Esc или нажатием вне панели. Содержимое панели — ваше; код отвечает за открытие, закрытие, фокус и прокрутку под панелью.
- **Для разработчика:** нативный `<dialog>` с состояниями `closed → opening → open → closing → closed`; фокус уходит внутрь и возвращается на кнопку открытия; быстрое «открыть-закрыть» не оставляет панель наполовину открытой; прокрутка под панелью блокируется и восстанавливается (в демо — только внутри области примера, страница каталога не блокируется); край на широком экране — слева, справа или снизу, на телефоне — снизу; свайп не обязателен.
- **Зачем платить:** бесплатных панелей нет, а панель — самое частое место, где ломаются фокус, Esc и прокрутка под ней. Здесь это решено в готовом коде.
- **Демо:** кнопка «Фильтры» → панель с несколькими полями и кнопкой «Закрыть»; на 375 — панель снизу.
- **Настройки:** длительность и анимация; край на широком экране (слева / справа / снизу) — переключатель в демо и свойство `edge` в коде.
- **Чем не является:** не готовое меню сайта и не окно подтверждения.

## 6. A007 · Оглавление с прогрессом чтения / Table of contents with reading progress (ТЗ: Scroll Chapters)

- **Категория:** Появление и скролл.
- **Простой слой:** для длинной страницы с разделами — статьи, документации, инструкции. Оглавление показывает, какой раздел читается сейчас и сколько страницы уже пролистано; нажатие на пункт переводит к разделу. Страница прокручивается как обычно.
- **Для разработчика:** контроллер сам считает активную главу и прогресс от обычной прокрутки (`IntersectionObserver` + измерение), без перехвата колёсика и касаний и без автопрокрутки; на телефоне — компактная полоса сверху; якорные ссылки и изменение размера окна работают обычно; наблюдатели снимаются при размонтировании.
- **Зачем платить:** бесплатное «Плавное появление содержимого» показывает блок один раз и не знает про разделы. Оглавление, которое следит за чтением, обычно делают через перехват прокрутки — и оно мешает читать. Здесь прокрутка остаётся обычной.
- **Демо:** статья из 4–5 разделов в области фиксированной высоты, оглавление и полоса прогресса закреплены внутри неё; на 375 — полоса сверху, без второй прокрутки поверх прокрутки страницы.
- **Настройки:** расположение оглавления на широком экране (сбоку / сверху), цвет акцента, анимация вкл/выкл.
- **Чем не является:** не «скролл-история» с закреплёнными сценами и не перехват прокрутки.

## 7. A008 · Плавная смена чисел / Animated number changes (ТЗ: Metric Roll)

- **Категория:** Текст и числа.
- **Простой слой:** когда число меняется — счётчик, показатель, цена, — цифры прокручиваются к новому значению, как на табло. Числа приходят от вашего сайта; эффект только показывает смену. Программа чтения с экрана сразу сообщает итоговое число, и при копировании копируется оно же.
- **Для разработчика:** форматирование через `Intl.NumberFormat` (разделители RU/EN/VI, валюта, знак, дробная часть); ленты цифр `aria-hidden`, для чтения — актуальное число одной строкой без объявления каждого кадра; ширина не прыгает (`tabular-nums`); при быстрых изменениях — сразу к последнему значению.
- **Зачем платить:** бесплатное «Появление заголовка по строкам» анимирует текст, а не числа. Самодельные счётчики ломаются на разделителях разных языков, отрицательных значениях и программах чтения с экрана; здесь это решено. От платного «Переключения показателей» набора Product отличается тем, что это анимация одного значения, а не готовая карточка.
- **Демо:** счётчик с кнопками «Уменьшить» и «Увеличить» (иконки с подписью для программ чтения) и показатель «за неделю», который меняется по кнопке «Следующая неделя» (не карточка цены).
- **Настройки:** длительность, формат чисел (RU / EN / VI), анимация вкл/выкл.
- **Чем не является:** не карточка метрик и не источник данных — числа приходят от сайта.

### E003 · Мягкий градиентный фон

- **Названия:** RU «Мягкий градиентный фон» · EN «Soft gradient background» · VI «Nền gradient mềm».
- **lead:** Спокойный цветной фон для одного блока страницы: цвета медленно перетекают за текстом и кнопками. Остановите движение, выберите цвет и характер движения и скачайте код.
- **demoHelp:** Фон уже движется за заголовком и кнопкой. «Пауза» останавливает движение, «Продолжить» запускает снова. Эта кнопка входит в скачиваемый код, чтобы посетитель вашего сайта тоже мог остановить фон. Когда блок уходит с экрана, фон останавливается сам.
- **useBody:** Для первого экрана или блока с главной кнопкой, где нужен живой, но не отвлекающий фон. Цвета по умолчанию подобраны так, чтобы текст поверх читался; если ставите свои, проверьте, что текст по-прежнему хорошо виден. Без анимации фон остаётся неподвижным.
- **promptBody:** Полный код и настройки. Вставьте запрос в ИИ-редактор своего React-проекта, чтобы добавить градиентный фон за нужным блоком.
- **guideBody:** Куда добавить файлы, как поставить фон за свой блок, задать цвета и проверить кнопку паузы и уменьшение движения.
- **settingsHelp:** Цвет, анимация и длительность применяются к примеру и файлам для скачивания. Длительность — за сколько фон плавно останавливается после «Паузы». Если выключить анимацию, фон останется неподвижным.
- **lead EN:** A calm color background for one section of a page: colors slowly drift behind text and buttons. Pause the motion, choose the color and motion style, and download the code.
