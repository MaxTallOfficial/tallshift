# SALE-04 · Описания платных анимаций UI Motion · 27.11.2026

Направление для приёмки Max Tall. Статус: дизайнер и копирайтер проверили («годится с правками», правки внесены) → ждёт «да» Max Tall. Кода нет; платный код появится только в приватном `tallshift-paid`.

Набор UI Motion по решению 27.11: E002 (делает сессия набора Product) + 7 позиций ниже. С ними все восемь категорий анимаций получают хотя бы один пример (раздел 6 дорожной карты).

**Как читать карточку.** «Простой слой» — что видит человек и куда это поставить; для тех, кто собирает сайт с ИИ-редактором. «Для разработчика» — что берёт на себя код. «Зачем платить» — почему это полезнее того, что есть бесплатно или пишется за вечер.

**Публичные названия.** По совету копирайтера предлагаем понятные названия вместо терминов ТЗ; название из ТЗ и ID остаются вторичными (правило AGENTS.md). Это часть направления на «да» Max Tall.

**Общее для всех семи:** React + TypeScript, CSS Modules, без зависимостей; демо — интерфейсная сцена без фото; цвета берутся из сайта или из значений по умолчанию (тёмная поверхность и шафрановый акцент, без второй темы ради демо); если у посетителя включено уменьшение движения или эффект выключен, содержимое сразу видно и работает; запрос для ИИ, инструкция RU/EN/VI, manifest, SHA-256 и ZIP — из одних настроек. Работа в чистых Next.js и Vite — критерий приёмки каждой позиции, а не обещание в тексте.

## 1. E003 · Мягкий градиентный фон / Soft Mesh Background

- **Категория:** Фоны и курсор.
- **Простой слой:** спокойный цветной фон за блоком — например за самым первым блоком сайта или блоком с главной кнопкой. Цвета медленно перетекают; кнопка «Пауза» останавливает движение. Цвета по умолчанию подобраны так, чтобы текст поверх читался; со своими цветами проверьте контраст.
- **Для разработчика:** 3–4 слоя CSS-градиентов внутри ограниченного контейнера, без WebGL и canvas; движение — только `transform`; пауза вне экрана и в скрытой вкладке; нативная кнопка Pause/Resume входит в экспорт; фон `aria-hidden`; статичная версия при `prefers-reduced-motion`.
- **Зачем платить:** фонов среди бесплатных примеров нет. Типичный градиент из интернета либо стоит на месте, либо перерисовывает весь экран и тратит батарею. Здесь готово то, что обычно забывают: пауза, остановка вне экрана, цвета сайта.
- **Демо:** блок с заголовком и кнопкой на анимированном фоне; кнопка «Пауза».
- **Настройки:** цвет акцента, скорость (медленно / очень медленно), анимация вкл/выкл.
- **Чем не является:** не фон на всю страницу и не генератор градиентов.

## 2. E004 · Подсветка за курсором / Cursor Spotlight (ТЗ: Pointer Spotlight)

- **Категория:** Фоны и курсор.
- **Простой слой:** мягкое пятно света следует за курсором внутри карточки. На телефоне подсветка спокойная и неподвижная. Кнопки и текст работают и без эффекта.
- **Для разработчика:** позиция через CSS-переменные, обновление не чаще кадра (`requestAnimationFrame`); слушатели только на своём блоке и только пока курсор внутри; слой `pointer-events: none`; на касаниях и при уменьшении движения — статичная подсветка; при фокусе с клавиатуры подсвечивается карточка целиком; полная очистка при размонтировании.
- **Зачем платить:** типичный копипаст вешает слушатель на всё окно и пересчитывает стили на каждое движение мыши. Здесь — только свой блок, один кадр, замена для клавиатуры и телефона. Самая лёгкая позиция набора; держит категорию «Фоны и курсор» вместе с E003.
- **Демо:** три карточки возможностей продукта (не тарифы), у каждой своя подсветка; на 375 — в одну колонку.
- **Настройки:** цвет, размер пятна, сила подсветки, анимация вкл/выкл.
- **Чем не является:** не «хвост» за курсором и не эффект на всю страницу.

## 3. A002 · Плавная смена содержимого / Smooth Content Switch (ТЗ: Context Bridge)

- **Категория:** Навигация и переходы.
- **Простой слой:** когда человек переключает раздел внутри блока — вкладку, шаг или фильтр, — старое содержимое уходит, новое появляется на том же месте, высота блока меняется плавно, страница не прыгает.
- **Для разработчика:** обёртка над содержимым, которое уже переключают ваши вкладки (например, бесплатный пример «Вкладки»): `current → incoming-ready → transition → current`. Новое содержимое показывается, когда оно готово, в том числе после загрузки; при быстрых переключениях побеждает последнее; высота анимируется по измерению; фокус передаётся по правилам приложения. Если выбор вкладки записан в адресе страницы, кнопки «Назад/Вперёд» браузера не ждут анимации.
- **Зачем платить:** бесплатные «Вкладки» меняют содержимое мгновенно. Переход ломается именно в неудобных случаях — загрузка ещё идёт, человек жмёт быстро, блоки разной высоты; здесь они решены.
- **Демо:** карточка «Возможности / Отзывы / Вопросы» с содержимым разной высоты и имитацией загрузки.
- **Настройки:** вид перехода (сдвиг / растворение), длительность, анимация вкл/выкл.
- **Чем не является:** не новые вкладки, не навигация по сайту и не переход между страницами.

## 4. A004 · Раскрытие карточки / Card Expand (ТЗ: Focus Plane)

- **Категория:** Карточки и медиа.
- **Простой слой:** нажали на карточку — она плавно разворачивается в подробный вид на том же месте; кнопка «Назад» в блоке сворачивает её обратно. Человек видит, откуда пришёл.
- **Для разработчика:** переход геометрии `idle → target-ready → morph → settled → return` по измерениям (FLIP), без копии, которая «улетает» при прокрутке или изменении размера окна; если подробный вид не готов — обычное открытие без анимации; кнопка возврата доступна с клавиатуры, фокус возвращается на исходную карточку.
- **Зачем платить:** бесплатные карточки и список не связывают «до» и «после». Связный переход часто просят, а самодельные версии ломаются на прокрутке, медленной загрузке и быстром повторном клике.
- **Демо:** 4–6 карточек проектов с разными мини-схемами интерфейса на обложке (не одинаковые плашки) → подробный вид с описанием и кнопкой «Назад».
- **Настройки:** длительность, скругление углов, анимация вкл/выкл.
- **Чем не является:** не галерея для просмотра фото и не готовая карточка проекта (это отдельные примеры после беты).

## 5. A005 · Выезжающая панель / Slide-out Panel (ТЗ: Edge Unfold)

- **Категория:** Панели и меню.
- **Простой слой:** панель выезжает сбоку, а на телефоне — снизу; подходит для меню, фильтров или корзины. Закрывается кнопкой, клавишей Esc или нажатием вне панели.
- **Для разработчика:** нативный `<dialog>` с состояниями `closed → opening → open → closing → closed`; фокус уходит внутрь и возвращается на кнопку открытия; быстрое «открыть-закрыть» не оставляет панель наполовину открытой; прокрутка под панелью блокируется и восстанавливается (в демо — только внутри области примера, страница каталога не блокируется); край — слева, справа или снизу; свайп не обязателен.
- **Зачем платить:** бесплатных панелей нет, а панель — самое частое место, где ломаются фокус, Esc и прокрутка под ней. Здесь это входит в готовый код и проверяется при приёмке.
- **Демо:** кнопка «Фильтры» → панель с несколькими полями; на 375 — панель снизу.
- **Настройки:** край (слева / справа / снизу), длительность, анимация вкл/выкл.
- **Чем не является:** не готовое меню сайта и не окно подтверждения.

## 6. A007 · Оглавление с прогрессом чтения / Reading Progress (ТЗ: Scroll Chapters)

- **Категория:** Появление и скролл.
- **Простой слой:** для длинной страницы с разделами: видно, какой раздел читается сейчас и какая часть страницы уже прочитана; нажатие на пункт оглавления переводит к разделу. Страница прокручивается как обычно.
- **Для разработчика:** контроллер сам считает активную главу и прогресс от обычной прокрутки (`IntersectionObserver` + измерение), без перехвата колёсика и касаний и без автопрокрутки; на телефоне — компактная полоса сверху; якорные ссылки и изменение размера окна работают обычно; наблюдатели снимаются при размонтировании.
- **Зачем платить:** бесплатное «Появление контента» показывает блок один раз и не знает про разделы. Оглавление, которое следит за чтением, обычно делают через перехват прокрутки — и оно мешает читать. Здесь прокрутка остаётся обычной.
- **Демо:** статья из 4–5 разделов в области фиксированной высоты, оглавление и полоса прогресса закреплены внутри неё; на 375 — полоса сверху, без второй прокрутки поверх прокрутки страницы.
- **Настройки:** расположение оглавления (сбоку / сверху), цвет акцента, анимация вкл/выкл.
- **Чем не является:** не «скролл-история» с закреплёнными сценами и не перехват прокрутки.

## 7. A008 · Прокрутка цифр / Number Roll (ТЗ: Metric Roll)

- **Категория:** Текст и числа.
- **Простой слой:** когда число меняется — счётчик, показатель, цена, — цифры прокручиваются к новому значению, как на табло. Программы чтения с экрана и копирование сразу получают итоговое число.
- **Для разработчика:** форматирование через `Intl.NumberFormat` (разделители RU/EN/VI, валюта, знак, дробная часть); ленты цифр `aria-hidden`, для чтения — актуальное число одной строкой без объявления каждого кадра; ширина не прыгает (`tabular-nums`); при быстрых изменениях — сразу к последнему значению.
- **Зачем платить:** бесплатная «Сборка строк заголовка» анимирует текст, а не числа. Самодельные счётчики ломаются на разделителях разных языков, отрицательных значениях и программах чтения с экрана; здесь это решено. От платного «Переключателя метрик» набора Product отличается тем, что это анимация одного значения, а не готовая карточка.
- **Демо:** счётчик с кнопками +/− и показатель «за неделю», меняющийся по кнопке (не карточка цены).
- **Настройки:** длительность, язык форматирования, анимация вкл/выкл.
- **Чем не является:** не карточка метрик и не источник данных — числа приходят от сайта.

## Проверки направления

- Дизайнер (27.11): годится с правками — убрана вторая тема в E003; E004 без тарифов и без противоречия про телефон; A002 — обёртка над вкладками, «Назад/Вперёд» только при адресе; A004 — разные мини-схемы; A005 — блокировка прокрутки только в области демо, «проверено» перенесено в критерии; A007 — область фиксированной высоты, убрана «пауза вне экрана»; A008 — без карточки цены, C004 не назван бесплатным; «Отклик контролов» как в ТЗ.
- Копирайтер (27.11): годится с правками — убраны жаргон и внутренние ID из простого слоя, смягчены обещания (контраст, «сколько осталось»), предложены понятные публичные названия.
