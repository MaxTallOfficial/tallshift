26.10.2026. Дополнение к ТЗ для следующего этапа реализации. Уточняет публичные названия, структуру рабочей области и пограничные состояния. Не является отчётом о готовом backend. Коммерческий расчёт задаёт [финальный контракт тарифов](pricing-final-contract.ru.md); фактические пробелы перечислены в [аудите](product-logic-audit-2026-10-26.ru.md).

Названия State Relay и других авторских материалов сопровождаются локализованной задачей. Коды S004/A001 и SKU не заменяют названия в карточках, составе заказа, тарифах и сообщениях. Технические имена файлов и API не переводятся. Исторические оплаченные заказы сохраняют исходное название и состав; переименование витрины не переписывает их.

## 2. Рабочая область: одна конфигурация, ясные границы

Три основные вкладки: Demo / Code / Prompt. Инструкция — постоянно доступное подписанное действие рядом с рабочей областью, открывающее отдельную панель; она также включена в ZIP. Это уточнение заменяет прежнее обязательное требование четвёртой вкладки Guide и соответствующую часть DES-04/WM09. Настройки доступны отдельно на мобильном. Режимы промпта оба доступны; выбранный режим отражается в копировании и ZIP.

Общий draft принадлежит выбранному материалу. Вкладки, локаль и адаптив не уничтожают введённые значения и выбранный файл. Смена языка не переводит пользовательские заметки и контекст. Смена Next.js/Vite меняет интеграционные файлы, а не права доступа.

| Действие/состояние | Обязательный результат |
| --- | --- |
| Введён другой валидный цвет, но не применён | Preview остаётся на применённом цвете. Copy code/prompt/ZIP заблокированы с текстом «Примените цвет или отмените изменение». Есть доступное действие возврата к применённому значению |
| HEX или другое поле невалидно | Ошибка у поля; preview сохраняет последний валидный результат. Конфигурационный экспорт заблокирован. Нельзя молча выдать прежние настройки |
| Apply | Применяет валидное значение; кнопка теряет акцент до следующего изменения; все форматы выдачи используют одну применённую конфигурацию |
| Импорт конфигурации | Контролы строятся по schema материала/версии. Для A001 допустим integer duration 0–480 ms; глобальные 0–400/step20 не должны обрезать валидные значения. Никакого тихого clamp |
| Reset preview | Перезапускает демонстрацию, не сбрасывает конфигурацию, контекст и наборы настроек |
| Clear fields | Очищает поля текущей формы создания набора настроек. Не удаляет сохранённые наборы и не меняет купленный доступ. Иконка корзины, доступное название и tooltip |
| Reset color | Сбрасывает только цвет выбранного материала |
| Удалить набор настроек | Удаляет только указанную сохранённую запись; не лицензию и не файлы проекта |
| Контекст проекта | Пустое свёрнутое opt-in поле, до 4000 символов, только память страницы. Явное пояснение перед включением в prompt/ZIP; не share/URL/analytics/localStorage. Не часть RecipeConfig |
| Сохранение в локальном стенде | Честно «на этой странице, до обновления». Будущее сохранение на устройстве требует отдельного действия; не сохранять контекст проекта вместе с ним |
| Копирование не удалось | Не показывать успех. Оставить текст доступным для ручного выделения; скачивание — независимое действие |

Schema конкретного материала первична для контролов. Версия контракта и миграции проверяются до применения; неизвестная/отозванная версия не подменяется автоматически ближайшей. Плановые A001 config/manifest fixtures обновлены до EN/RU/VI 26.10.2026; это не подтверждение готовности релиза. Старые двухъязычные записи остаются читаемыми для совместимости, новые публикации обязаны включать три языка.

## 3. Покупка, доступ и обновления

Пользователь видит состав и цену до оплаты. Купленные материалы, файлы в наличии и срок функциональных обновлений — три независимых признака. Владение кодом бессрочно; окончание 12 месяцев обновлений не отнимает полученный код. Безопасность и EOL регулирует инженерное ТЗ: минимум 24 месяца поддержки линии от первого платного выпуска, предупреждение EOL за 90 дней, безопасная замена/патч при отзыве.

| Сценарий | Что показываем и делаем |
| --- | --- |
| Новый покупатель Product | 6 материалов, $16 разово, один автор, личные и клиентские конечные проекты, 12 месяцев функциональных обновлений |
| Новый покупатель All packs | 4 текущих платных набора, 23 уникальных материала, $39 разово. Бесплатные 9 доступны отдельно всем; они не увеличивают платный счётчик |
| Product за $16 → All packs | $23 за 17 новых материалов. Старые 6 сохраняют прежние даты обновлений; новые 17 получают своё 12-месячное окно. Персональная сводка обязана показать обе группы и даты |
| Другие пересечения покупок | Сервер считает best-eligible цену по финальному контракту. Показать принадлежащие и новые материалы, итог и срок действия предложения. Не суммировать скидки поверх друг друга |
| Уже принадлежит весь состав | «Открыть мои материалы», без повторной оплаты. Повторная покупка не продлевает обновления; SKU продления в v1 нет |
| Product возвращён после доплаты | Остаются 17 купленных доплатой материалов; исходные 6 недоступны по возвращённому заказу, если нет другого действующего основания доступа. Показать частичный доступ 17/23, не полное All packs |
| Срок обновлений закончился | Показать доступную приобретённую редакцию и дату окончания функциональных обновлений. Не «доступ закрыт» и не требование купить код снова |
| Права загружаются / запрос не удался | «Проверяем покупки» / «Не удалось проверить, повторить». Не выдавать непроверенное состояние за отсутствие покупки |
| Платёж ещё обрабатывается | Ожидание статуса заказа; повторный запрос безопасен. Новая попытка не должна создать второй платёж по тому же намерению |
| Оплата подтверждена, доступ ещё оформляется | Отдельное состояние «Оплата получена, готовим доступ», номер заказа и повторная проверка. Не предлагать повторную покупку |
| Checkout закрыт, позже пришёл paid webhook | Закрытие окна не отменяет подтверждённый сервером платёж; показать успешный заказ и фактический доступ |
| Цена/владение изменились до оплаты | Пересчитать и показать новую сводку до подтверждения; не списывать разницу без действия пользователя. Зафиксированный оплаченный заказ сверяется идемпотентно |
| Доступ есть, файл временно не выдаётся | Ошибка скачивания и повтор; сохраняются права. Не заменять состояние на «купить» |
| Архив Pro | Потоковая выдача с авторизацией и проверкой прав/релиза на каждом запросе; не публичная подписанная ссылка. Клиентское скрытие кнопки не является проверкой прав |
| Share | Передаёт разрешённую конфигурацию и ссылку на материал; не лицензию, приватный код или контекст проекта |

Покупка привязана к стабильному user ID, подтверждённому сервером при checkout; смена email не меняет владельца. Email плательщика сам по себе не даёт права привязать заказ к другому аккаунту. Восстановление после потери входа/удаления аккаунта требует проверенного процесса поддержки: подтверждение личности и заказа, аудит переноса, отзыв прежней привязки, без повторной оплаты и без автоматической выдачи по введённому адресу. Сроки хранения платёжных записей и допустимость восстановления после удаления закрепляются в условиях продавца до запуска; не обещать хранение удалённых персональных данных без основания.

Налоги и финальная сумма до подтверждения оплаты рассчитываются сервером/провайдером. Локальный pricing helper считает только цену состава до налогов. Цена, права и доступность файла не принимаются из браузера. Готовые карточки дизайн-системы не означают работающий checkout.

## 4. Условия приёмки следующего этапа

1. Во всех EN/RU/VI маршрутах одинаковые состав, цена, значение статусов и названия предложений; нет пользовательских списков из одних ID.
2. Каталог и раздел анимаций показывают один материал, общие избранное/доступ/конфигурацию; 12 анимаций не прибавляются к общим 32.
3. Проверены новый покупатель, частичное владение, полное владение, истёкшие обновления, возврат исходной покупки после доплаты, подтверждённая оплата без готового доступа, сбой выдачи при действующих правах.
4. Два экспорта с разными применёнными настройками согласованы в code/prompt/instructions/ZIP; невалидный и неприменённый draft не выдаются за экспорт текущего состояния.
5. Инструкция открывается из рабочей области, оба режима промпта различимы, исходники интегрируются в Next.js/Vite. Проверки трёх языков включают длинные строки и ошибки.
6. Подтверждена серверная реализация, а не только локальные демонстрационные состояния. Публичная продажа отдельно проходит readiness gates каждого материала, платежей и условий продавца.
