# Tallshift — каталог и страница материала

Первый продуктовый этап на текущей дизайн-системе Afterlight / Foundations 10: Manrope, Saffron Lighter `#EBD183`, общие компоненты и scoped tracker ввода. EN — основной, RU/VI — дополнительные языки.

Каталог, страница работающего A001 State Relay и описания остальных 31 плановых материалов с иллюстрациями концепций. Код и скачивание плановых материалов закрыты. Это локальный продуктовый preview, не публичный выпуск библиотеки.

Требования: Node.js 24.19.0, npm 11.17.0. Из этой папки:

```sh
npm ci
npm run dev
```

Откройте адрес Local из терминала, обычно `http://127.0.0.1:4173/en/library`. Другие языки — `/ru/library`, `/vi/library`. State Relay — `/{locale}/library/state-relay`. Корень открывает английский каталог. Для остановки нажмите Ctrl+C.

Проверки:

```sh
npm test
node tests/verify-export.mjs
npm run build
```

`npm test` проверяет модель каталога, маршруты, систему и контроллер. `npm run test:study` проверяет 12 сочетаний EN/RU/VI × Next/Vite × preserve/adapt: соответствие текущему Afterlight preview, промпт, ZIP roundtrip, SHA-256 и детерминированность. `verify-export.mjs` сохранён для исторического комплекта. Собранную версию можно запустить через `npm run preview -- --port 4173`.

Материал имеет три вкладки Demo / Code / Prompt и отдельную инструкцию. Настройки меняют акцент, движение и длительность, target и режим промпта; можно копировать файлы/промпт и скачать комплект. Невалидный или неприменённый draft блокирует выдачу; все результаты соответствуют одной применённой конфигурации. Project context включается явно, ограничен 4000 символами и существует только в памяти страницы; он попадает в промпт при явном копировании/скачивании. В share URL — только версия рецепта, акцент и движение. Избранное хранится локально, при недоступном storage работает до закрытия страницы с видимым пояснением.

Clipboard работает на localhost/HTTPS и может требовать разрешение браузера. Success следует только после реального результата. Отдельный сценарий ошибки явно обозначен как локальная симуляция.

Проверки Vite используют временный кеш: при одновременном `npm test` и dev возможен `Outdated Optimize Dep`; запустите dev после завершения тестов. Системный стенд сохранён отдельно в `art-direction/foundations/review.html`. Исторические `src/App.tsx` и `src/styles.css` больше не являются основной точкой входа.
