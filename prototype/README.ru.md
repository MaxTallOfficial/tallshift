# Formrift — локальный проверочный прототип

Текущий этап — [Foundations / 06: системный стенд](../art-direction/foundations/review.html), EN основной, RU/VI дополнительные. [Описание и проверки](../docs/art-direction-2026/foundations-06.ru.md). [Afterlight / 05](../art-direction/afterlight/review.html) сохранён отдельно; светлая оболочка ниже — исторический функциональный прототип RU/EN.

Главная, каталог, раздел анимаций и Studio для одного работающего A001 State Relay. Остальные 31 карточка — плановые описания с иллюстративными CSS-композициями. Это приложение для проверки ТЗ, не публичный релиз библиотеки.

Требования: Node.js 24.19.0, npm 11.17.0. Из этой папки:

```sh
npm ci
npm run dev
```

Откройте адрес Local из терминала, обычно `http://127.0.0.1:4173/ru`. Английская версия — `/en`. Для остановки нажмите Ctrl+C.

Проверки:

```sh
npm test
node tests/verify-export.mjs
npm run build
```

`npm test` проверяет контроллер и безопасную appearance-ссылку. `verify-export.mjs` проверяет восемь сочетаний RU/EN × Next/Vite × preserve/adapt: ZIP roundtrip, реальные SHA-256, равенство исходникам и детерминированность. Он сохраняет готовый пример в `artifacts/A001-state-relay-vite-ru.zip`.

Studio позволяет менять акцент, движение и длительность, выбирать target и режим промпта; копировать файлы/промпт и скачивать полный комплект. Project context существует только в памяти вкладки; он попадает в промпт при явном копировании/скачивании. В share URL — только версия рецепта, акцент и параметры движения. Избранное хранится локально, при недоступном storage работает до закрытия страницы.

Clipboard работает на localhost/HTTPS и может требовать разрешение браузера. Success следует только после реального результата. Отдельный сценарий ошибки явно обозначен как локальная симуляция.

Оплата, аккаунты, серверный AI, production preview isolation и 31 оставшийся runtime не реализованы. Production-контракты и release gates заданы в `../docs/product-spec-v1.0.ru.md`. Проверки и их ограничения: `../docs/spec-v1.0/prototype-verification.ru.md` и `recipe-verification.ru.md`.
