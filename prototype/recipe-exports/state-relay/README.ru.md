# State Relay / A001@0.1.0-prototype

Рабочий локальный рецепт React + TypeScript под MIT. Скопируйте папку целиком и импортируйте SelectedExample.tsx. Стандартные параметры: EN, subtle, #3569ed, 120ms. Поддерживаются EN/RU/VI. Сгенерированный ZIP содержит выбранные в Studio параметры.

Полная установка: INSTALL.ru.md. Интеграция: INTEGRATE.ru.md. Лицензия: LICENSE.txt. Внешних motion-зависимостей нет; React 19.3.1 предоставляется проектом; другие версии отдельно не проверены.

`Example.tsx` использует настоящую Clipboard-операцию. «Ошибка · симуляция» — явно обозначенный локальный сценарий. Pending не удерживается таймером, поздний success не перезаписывает новую ошибку. Настройки off/reduce отключают движения, сохраняя информацию и фокус.

Тесты чистого контроллера: Node 24+, `node --test controller.test.mjs`. Сборка в целевом Next.js/Vite и браузерные проверки выполняются отдельно; фактические результаты находятся в отчёте прототипа. Это не опубликованный production-релиз всей библиотеки.
